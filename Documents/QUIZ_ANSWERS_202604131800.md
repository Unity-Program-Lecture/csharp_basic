# 🔑 C# 기초 강의 퀴즈 정답지

본 문서는 1일차부터 10일차까지의 핵심 퀴즈에 대한 정답과 해설을 담고 있습니다.

---

## 📅 1주차: C# 기초 및 객체지향 기초

### 1일차: 기초 문법
1. **변수 이름을 지을 때 숫자로 시작할 수 있나요?**
   - **정답:** X (숫자로 시작할 수 없으며, 영문자나 언더바`_`로 시작해야 합니다.)
2. **`int age = 20.5;` 코드는 정상적으로 작동할까요?**
   - **정답:** X (int는 '정수'만 담을 수 있습니다. 20.5 같은 실수는 `float`나 `double`을 써야 합니다.)

### 2일차: 제어 흐름
1. **`10 / 3`의 결과값은 얼마인가요?**
   - **정답:** 3 (정수와 정수의 나눗셈 결과는 소수점을 버린 정수값이 나옵니다.)
2. **`for`문과 `while`문의 가장 큰 차이점은 무엇인가요?**
   - **정답:** `for`문은 반복 횟수가 명확할 때(예: 10번) 주로 쓰고, `while`문은 특정 조건이 참인 동안(예: HP가 0보다 클 때) 계속 반복할 때 주로 씁니다.

### 3일차: 메소드와 클래스
1. **외부에서 절대 건드리지 못하게 하려면 어떤 키워드를 붙여야 하나요?**
   - **정답:** `private`
2. **`static`이 붙은 메소드와 그렇지 않은 메소드의 가장 큰 차이는 무엇인가요?**
   - **정답:** `static` 메소드는 클래스의 실체(new)를 만들지 않아도 바로 쓸 수 있지만, 일반 메소드는 반드시 `new`로 객체를 만들어야만 쓸 수 있습니다.

### 4일차: 생성자와 상속
1. **부모의 메소드를 자식이 바꿀 수 있게 허용하려면 부모 쪽에 어떤 키워드를 붙이나요?**
   - **정답:** `virtual`
2. **자식 클래스에서 부모 클래스의 생성자를 호출할 때 사용하는 키워드는?**
   - **정답:** `base`

### 5일차: 배열과 랜덤
1. **`int[5]` 배열에서 마지막 칸의 인덱스 번호는?**
   - **정답:** 4번 (0부터 시작하므로 0, 1, 2, 3, 4가 다섯 칸입니다.)
2. **`Random.Next(1, 10)`에서 10이 나올 수 있나요?**
   - **정답:** X (두 번째 숫자는 '미만'을 의미하므로 1부터 9까지만 나옵니다.)

## 📅 2주차: 인터페이스 및 컬렉션

### 6일차: 인터페이스
1. **클래스 상속과 인터페이스 구현의 가장 큰 차이점은?**
   - **정답:** 클래스 상속은 오직 하나만 가능하지만, 인터페이스는 여러 개를 동시에 구현할 수 있습니다.
2. **인터페이스 안에 변수를 선언할 수 있나요?**
   - **정답:** X (인터페이스는 '기능의 약속'만 담으므로 변수를 가질 수 없습니다.)

### 7일차: 컬렉션 (List, Dictionary)
1. **`List`에서 특정 위치의 데이터를 지우는 메소드는?**
   - **정답:** `RemoveAt(인덱스번호)`
2. **`Dictionary`에서 중복된 'Key'를 가질 수 있나요?**
   - **정답:** X (Key는 유일해야 합니다. 중복된 Key를 넣으려 하면 에러가 발생합니다.)

### 8일차: 제네릭 (Generics)
1. **제네릭에서 사용하는 `<T>`는 무엇의 약자인가요?**
   - **정답:** Type (타입)
2. **제네릭을 사용하면 어떤 장점이 있나요?**
   - **정답:** 코드 중복을 줄일 수 있고, 데이터 타입을 안전하고 빠르게 처리할 수 있습니다.

### 9일차: Stack과 Queue
1. **"나중에 들어온 것이 먼저 나간다"는 특징을 가진 자료구조는?**
   - **정답:** Stack (스택)
2. **큐(Queue)에서 데이터를 넣고 뺄 때 사용하는 메소드는?**
   - **정답:** 넣을 때 `Enqueue`, 뺄 때 `Dequeue`

### 10일차: 종합 미션
1. **'이름'으로 데이터를 빠르게 찾기에 가장 적합한 바구니는?**
   - **정답:** Dictionary (딕셔너리)
2. **`List<Item>`에 `Potion`과 `Weapon`을 동시에 담을 수 있는 이유는?**
   - **정답:** 두 클래스 모두 `Item` 클래스를 상속받았거나 같은 인터페이스를 구현했기 때문입니다. (다형성)

## 📅 3주차: 고급 문법 및 이벤트 시스템

### 11일차: 예외 처리
1. **무조건 마지막에 실행되어야 하는 코드는 어느 블록에 넣나요?**
   - **정답:** `finally`
2. **유니티에서 변수에 오브젝트를 연결하지 않고 사용할 때 발생하는 에러의 이름은?**
   - **정답:** `NullReferenceException` (널 레퍼런스 익셉션)
