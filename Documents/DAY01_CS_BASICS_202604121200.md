## [2교시] 14:00 ~ 15:30 | 실습 1: 환경 설정 및 첫 코드

### 1. Visual Studio 2022 설치 가이드
- **설치 프로그램:** Visual Studio Installer 실행
- **워크로드 선택 (필수):**
  - [X] .NET 데스크톱 개발 (콘솔 앱 제작용)
  - [X] C#을 이용한 게임 개발(Unity) (나중을 위해 미리 체크)
- **설치 확인:** 설치 완료 후 로그인이 나오면 '나중에 로그인'을 선택해도 무방합니다.

### 2. 첫 프로젝트 생성
1. '새 프로젝트 만들기' 클릭
2. **'콘솔 앱' (C#)** 선택
3. 프로젝트 이름: `MyFirstConsole`
4. 프레임워크: `.NET 6.0` 또는 `.NET 8.0` (가장 최신 권장)

### 3. Hello World 코드 작성
```csharp
using System;

namespace MyFirstConsole
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, World!");
            Console.WriteLine("내일부터 시작될 C# 선행 학습을 환영합니다!");
        }
    }
}
```

### 💡 [보충] 코드의 구성 요소 이해하기
C# 코드를 처음 보면 복잡해 보이지만, 핵심은 **'집(Class)'**과 **'시작 버튼(Main)'**입니다.

1. **internal class Program (프로그램의 집)**
   - C#의 모든 코드는 반드시 `class`라는 울타리 안에 있어야 합니다.
   - `Program`은 이 프로젝트의 전체 로직을 담고 있는 가장 큰 상자(집)의 이름입니다.

2. **static void Main(string[] args) (시작 단추)**
   - 컴퓨터가 프로그램을 실행할 때 가장 먼저 찾아가서 누르는 **'엔트리 포인트(시작점)'**입니다.
   - **static:** 프로그램을 실행하자마자 즉시 메모리에 올려서 바로 사용할 수 있게 합니다.
   - **void:** 이 함수가 일을 마친 후 컴퓨터에게 따로 돌려줄 보상(결과값)이 없다는 뜻입니다.
   - **Main:** 컴퓨터와의 약속된 이름입니다. 무조건 이 이름을 가진 곳에서 실행을 시작합니다.
   - **string[] args:** 외부에서 프로그램 실행 시 전달하는 옵션값들입니다. (기초 단계에선 비워둡니다.)

## [3교시] 16:00 ~ 17:30 | 실습 2: 변수(Variable)와 자료형

### 1. 변수란 무엇인가?
- 데이터를 담는 '상자'입니다. 
- 상자에는 이름(변수명)과 담을 데이터의 종류(자료형)가 정해져 있어야 합니다.

### 2. 핵심 자료형 4가지
| 자료형 | 이름 | 설명 | 예시 |
| :--- | :--- | :--- | :--- |
| **int** | 정수형 | 소수점이 없는 숫자 | 10, -5, 100 |
| **float** | 실수형 | 소수점이 있는 숫자 (뒤에 `f` 붙임) | 3.14f, 0.5f |
| **string** | 문자열 | 큰따옴표 안에 들어가는 글자 | "Gemini", "C# 기초" |
| **bool** | 논리형 | 참과 거짓 | true, false |

### 3. 변수 사용 실습 코드
```csharp
int age = 25;
float height = 175.5f;
string name = "홍길동";
bool isStudent = true;

Console.WriteLine("이름: " + name);
Console.WriteLine("나이: " + age);
Console.WriteLine("키: " + height + "cm");
Console.WriteLine("학생 여부: " + isStudent);
```

## [4교시] 17:30 ~ 18:00 | 정리 및 리뷰

### 오늘의 핵심 정리
- **주석(Comment):** 코드에 설명을 다는 기능 (컴퓨터는 읽지 않음)
  - `//` : 한 줄 주석
  - `/* ... */` : 여러 줄 주석
- **세미콜론(;):** C# 문장의 마침표입니다. 문장이 끝나면 반드시 찍어야 합니다.
