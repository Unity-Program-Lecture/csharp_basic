## Part 2: 평가자 체크리스트 실기 과제

### 1. 과제명
* **과제명**: "**Unity 6 URP 기반의 3D 물리/수학 시뮬레이터 및 A* 길찾기 AI가 탑재된 UGUI 인벤토리 프로토타입 구현**"

### 2. 과제 개요
* 훈련생은 본인이 배운 게임 수학, 물리, 자료구조, 알고리즘을 종합하여 Unity 6 환경에서 구동되는 시뮬레이터 프로토타입을 제작합니다.
* 기획서의 자연어 요구사항을 정확히 분석하여 자료구조와 클래스 구조를 설계하는 **기술 디자인 문서** (TDD, Class Diagram 포함)를 먼저 작성하고, 이를 바탕으로 실제 고성능 C# 스크립트를 구현 및 배포합니다.

### 3. 주요 수행 과제 세부 내역

#### Task 1: 3D 수학 시뮬레이션 및 URP 커스텀 렌더링
* 플레이어와 몬스터 오브젝트를 배치하고 마우스/키보드 입력 시스템으로 제어합니다.
* 두 오브젝트의 상대 벡터 연산($B - A$)을 계산하여 실시간 추적 로직 및 거리를 화면에 디스플레이합니다.
* 카메라 절두체(Frustum Plane 6개)를 기하학적으로 시각화하고, 절두체 영역 밖으로 벗어난 오브젝트가 Gizmos 또는 UI 상에서 Culling 상태로 전환되는 수학적 Frustum Culling 알고리즘을 구현합니다.
* 최신 URP의 Shader Graph를 이용하여 오브젝트가 추적 범위 내에 들어왔을 때 색상이 흐르는 듯한 커스텀 렌더링 효과를 셰이더로 제작하여 적용합니다.

#### Task 2: 물리 기반 발사체 시뮬레이터
* 타겟을 향해 발사체를 투사하는 시스템을 만듭니다.
* 발사체에는 등가속도 법칙, 중력(Gravity), 공기 저항(Drag, 항력) 수식이 실시간 프레임(`Time.deltaTime`) 단위로 정확히 계산 및 누적되도록 직접 수학 포뮬러를 적용한 스크립트를 빌드합니다. (상용 Rigidbody의 단순 AddForce에 의존하지 않고 수학적으로 궤적 계산)
* 바닥 또는 장애물 충돌 시 반발 계수(e)에 따른 감쇠 및 튕김 궤적을 운동량 보존 법칙에 근거하여 구현합니다.

#### Task 3: 자연어 데이터 기획 분석 기반 UGUI 인벤토리 시스템
* 제공되는 아이템 기획서(자연어 문서)를 분석하여 아이템 데이터 구조(ID, 이름, 능력치, 타입)를 도출하고, 이를 바탕으로 한 자료구조 데이터 설계 문서(클래스 구조 다이어그램)를 제출합니다.
* 추출된 데이터를 메모리상에 적재하고 검색 속도를 보장하기 위해 `Dictionary<int, Item>` 구조를 채택하여 구현합니다.
* 게임 런타임 내 화면 표시는 **UGUI(Canvas, RectTransform, EventSystem)**를 활용하여 빌드하며, 각 아이템 슬롯은 `IPointerEnterHandler`, `IPointerExitHandler` 인터페이스를 상속받은 C# 스크립트를 통해 마우스 호버링 툴팁 인터랙션을 동적으로 바인딩합니다. Text는 최신 **TextMesh Pro (TMP)**를 기본 적용합니다.

#### Task 4: A* 알고리즘 길찾기 및 AI 에이전트 구현
* 장애물이 배치된 타일 격자(Grid) 맵을 구축하고, 타일 유형(일반 타일: 이동 비용 1, 늪지대 타일: 이동 비용 3)을 설정합니다.
* 출발지에서 목적지까지 $F = G + H$ 공식 및 Open/Closed List 루프 연산을 정밀하게 수행하여 가중치 최단 경로를 실시간으로 탐색하는 A* 알고리즘 모듈을 구현합니다.
* 몬스터 에이전트는 A* 경로 탐색 데이터와 FSM(유한 상태 머신: Idle ➡️ Patrol ➡️ Chase ➡️ Attack)을 연동하여 지능적으로 플레이어를 추격하도록 제어 스크립트를 작성합니다.
* 스크립트 오류 발생 시 `try-catch-finally` 구문 또는 예외 안전 코드를 적용하여 런타임 크래시 결함(Infinite Loop, NullReference)을 방어적으로 차단합니다.
