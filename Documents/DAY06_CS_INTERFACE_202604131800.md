# 🚀 6일차: 우리 사이의 약속! (인터페이스)

오늘의 목표는 **"구체적인 구현은 미루고, 어떤 기능이 반드시 있어야 하는지 '설계 규칙'을 정하는 방법(인터페이스)을 배운다"**입니다.

---

## 1. 인터페이스(Interface): "사용 설명서 혹은 계약서"
클래스가 "나는 누구인가(설계도)"를 정의한다면, 인터페이스는 **"나는 이런 일을 할 수 있다(기능 약속)"**를 정의합니다.

### 💡 이 단어는 무슨 뜻인가요?
- **`interface` (인터페이스)**: 실제 알맹이(코드)는 없고 이름만 있는 메소드들의 모임입니다.
- **`I` 접두사**: C#에서는 인터페이스 이름 앞에 대문자 **'I'**를 붙이는 것이 약속입니다. (예: `IDamageable`)
- **구현 (Implementation)**: 인터페이스에 적힌 약속을 클래스에서 실제로 지키는(코드를 쓰는) 것을 말합니다.

### 💻 실습 예제: 데미지를 입을 수 있는 모든 것들
**미션:** IDamageable 인터페이스를 정의하고, 플레이어와 나무 클래스에서 각각의 특색에 맞게 데미지 처리 기능을 구현해 보세요.

<details>
<summary>코드 보기</summary>

```csharp
using System;

namespace Day06
{
    // 1. "데미지를 입을 수 있다"는 약속을 만듭니다.
    interface IDamageable
    {
        void TakeDamage(int amount); // "이걸 가진 애들은 무조건 이 기능을 만들어야 해!"
    }

    // 2. 플레이어는 데미지를 입을 수 있습니다.
    class Player : IDamageable
    {
        public int hp = 100;
        public void TakeDamage(int amount)
        {
            hp -= amount;
            Console.WriteLine("플레이어가 {0}의 데미지를 입었습니다. (남은 HP: {1})", amount, hp);
        }
    }

    // 3. 나무(오브젝트)도 데미지를 입을 수 있습니다.
    class Wood : IDamageable
    {
        public int durability = 50;
        public void TakeDamage(int amount)
        {
            durability -= amount;
            Console.WriteLine("나무가 쪼개집니다! (남은 내구도: {0})", durability);
        }
    }

    internal class Program
    {
        static void Main(string[] args)
        {
            // 인터페이스의 강력함: 타입이 달라도 같은 약속을 지켰다면 하나로 묶을 수 있습니다!
            IDamageable target1 = new Player();
            IDamageable target2 = new Wood();

            target1.TakeDamage(10);
            target2.TakeDamage(10);
        }
    }
}
```

</details>

## 2. 왜 인터페이스를 쓰나요?
1. **표준화**: 여러 사람이 작업할 때, 메소드 이름을 통일할 수 있습니다.
2. **유연함**: 나중에 새로운 클래스가 추가되어도, 같은 인터페이스만 쓰고 있다면 기존 코드를 고칠 필요가 없습니다.
3. **다중 구현**: 클래스 상속은 한 명의 부모만 가질 수 있지만, 인터페이스 약속은 **여러 개**를 동시에 지킬 수 있습니다.

### 💻 실습 예제: 하늘을 나는 강아지?
**미션:** 여러 인터페이스를 한 클래스에서 동시에 구현(다중 구현)하여 다양한 기능을 가진 복합 객체를 만들어 보세요.

<details>
<summary>코드 보기</summary>

```csharp
interface IFlyable { void Fly(); }
interface IWalkable { void Walk(); }

// 강아지는 걷기도 하고, (마법으로) 날 수도 있습니다!
class MagicDog : IWalkable, IFlyable
{
    public void Walk() { Console.WriteLine("강아지가 걷습니다."); }
    public void Fly() { Console.WriteLine("강아지가 하늘을 납니다!"); }
}
```

</details>
