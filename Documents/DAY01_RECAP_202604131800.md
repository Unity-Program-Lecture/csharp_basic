# 📝 1일차: 프로그래밍의 기초 (다시 보기)

오늘 처음 배운 내용은 프로그래밍이라는 새로운 언어의 '단어'와 '문법'입니다. 어렵게 느껴지는 것이 당연하니, 아래 비유로 다시 기억을 떠올려 보세요!

### 🔍 코드 읽기 3원칙 (컴퓨터처럼 생각하기)
코드를 보면 어디부터 읽어야 할지 막막하죠? 딱 3가지만 기억하세요.
1. **위에서 아래로**: 컴퓨터는 위에서부터 한 줄씩 실행합니다.
2. **오른쪽에서 왼쪽으로 (`=` 기호)**: `int a = 10;`은 "10을 상자 `a`에 넣어라"는 뜻입니다. 오른쪽 결과를 먼저 계산하고 왼쪽 상자에 담습니다.
3. **안쪽에서 바깥쪽으로 (괄호 `()`):** `int.Parse(Console.ReadLine())`은 "입력을 먼저 받고(`ReadLine`), 그 결과를 숫자로 바꿔라(`Parse`)"는 순서입니다.

### 1. 변수와 데이터 타입 (박스와 이름표)
- **변수**: 데이터를 담는 **상자**입니다.
- **데이터 타입**: 상자의 **크기와 종류**입니다.
    - `int`: 정수(숫자)만 담는 튼튼한 상자.
    - `float`: 소수점(정밀한 숫자)을 담는 상자.
    - `string`: 글자들을 한 줄로 꿰어 놓은 실타래.
    - `bool`: 전등 스위치 (딱 두 가지 상태: 켜짐/꺼짐).

### 2. 값 형식 vs 참조 형식 (진품 vs 리모컨)
- **값 형식(int, bool 등)**: 상자 안에 **진짜 물건**이 들어있습니다. 친구에게 주면 똑같은 물건을 하나 더 만들어 주는 것과 같습니다.
- **참조 형식(string, class 등)**: 상자 안에 물건이 너무 커서 못 넣고, 대신 그 물건을 조종하는 **리모컨(주소)**만 들어있습니다. 친구에게 주면 같은 물건을 조종할 수 있는 '리모컨'을 하나 더 주는 것입니다.

### 3. 함수 (자판기)
- 동전(입력)을 넣고 버튼을 누르면, 안에서 복잡한 기계가 작동해서 음료수(출력)가 나옵니다. 우리는 안에서 무슨 일이 일어나는지 몰라도 **"버튼만 누르면(호출)"** 결과를 얻을 수 있습니다.

### 4. 제어문 (인생의 선택지)
- **if/else**: 갈림길입니다. "배가 고픈가?"라는 질문에 `yes`면 식당으로, `no`면 카페로 가는 흐름입니다.
- **for**: 운동장 돌기입니다. "10바퀴만 돌아!"라고 명확하게 횟수를 정해주고 반복하는 것입니다.
