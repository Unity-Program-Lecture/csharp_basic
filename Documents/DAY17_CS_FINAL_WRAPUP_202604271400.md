## 1. 비동기(Async/Await): "기다리는 동안 딴짓하기"
컴퓨터가 어떤 일을 처리하는 동안(예: 로딩, 다운로드), 프로그램이 멈춘 것처럼 보이지 않게 뒤에서 조용히 처리하는 기술입니다.

### 💡 이 단어는 무슨 뜻인가요?
- **`async`**: "이 메소드는 **비동기**로 작동할 거야!"라고 미리 알리는 키워드입니다.
- **`await`**: "이 일이 끝날 때까지 기다리되, 다른 일은 계속하고 있어!"라는 뜻입니다.
- **`Task`**: 비동기로 처리될 **'일거리'** 그 자체를 의미합니다.

### 💻 실습 예제: 타이머와 인사하기
**미션:** `Task.Delay`를 사용하여 2초 뒤에 인사를 하는 코드를 작성하되, 그동안 다른 코드도 실행되는지 확인해 보세요.

<details>
<summary>코드 보기</summary>

```csharp
using System;
using System.Threading.Tasks; // 비동기를 위해 필수!

namespace Day16
{
    internal class Program
    {
        static async Task SayHelloAsync() // 비동기 메소드 선언
        {
            Console.WriteLine("인사 준비 중...");
            await Task.Delay(2000); // 2초 동안 기다립니다. (그동안 메인 코드는 계속됨)
            Console.WriteLine("안녕! 나는 비동기 로봇이야.");
        }

        static async Task Main(string[] args)
        {
            Task task = SayHelloAsync();
            
            Console.WriteLine("인사를 기다리는 동안 나는 다른 일을 합니다.");
            Console.WriteLine("1, 2, 3... 카운트다운!");

            await task; // 마지막에는 인사가 끝날 때까지 기다려줍니다.
        }
    }
}
```

</details>

## 3. 16일차 심화 미션: "전투 연출과 비동기 루프"

**[미션 목표]**
비동기(`async/await`)를 사용하여 전투가 즉각적으로 끝나는 것이 아니라, 1초마다 긴장감 있게 진행되는 '진짜 턴제 전투'의 연출을 구현합니다.

---

### 1) 요구 사항

#### 1. 시간차 전투 연출
* 플레이어가 공격했을 때, 결과가 바로 나오지 않고 1초의 딜레이를 줍니다. (`await Task.Delay(1000)`)
* "플레이어가 기를 모읍니다..." -> 1초 뒤 -> "공격 성공!" 메시지가 뜨게 만듭니다.

#### 2. 비동기 게임 루프
* 전체 게임 진행을 `GameStartAsync()`라는 비동기 메서드로 감쌉니다.
* 몬스터가 공격할 때도 짧은 딜레이를 주어 사용자가 전투 흐름을 읽을 수 있게 설계합니다.

#### 3. 리팩토링 (정리 정돈)
* 지금까지 흩어져 있던 클래스들을 각자의 파일로 나누고(Partial 클래스 혹은 별도 파일), 중복되는 코드를 깔끔하게 정리합니다.

---

### 2) 프로그래밍 힌트
* `Console.WriteLine` 사이에 `await Task.Delay()`를 넣으면 훌륭한 게임 연출이 됩니다.
* 모든 작업이 끝난 뒤에 `Console.Clear()`를 적절히 사용하면 화면이 깔끔해집니다.
* 3주 동안 작성한 코드는 여러분의 소중한 자산입니다. 주석을 꼼꼼히 달아 나만의 C# 포트폴리오를 만들어 보세요.
