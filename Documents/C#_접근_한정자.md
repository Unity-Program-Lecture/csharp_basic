# C# 접근 한정자 (Access Modifiers) 정리

접근 한정자는 클래스나 멤버의 가시성을 제어하여 객체 지향의 핵심인 **캡슐화**를 구현하는 도구입니다.

## 1. 주요 한정자 4가지

| 한정자 | 설명 | 접근 범위 |
| :---- | :---- | :---- |
| **public** | 공공의 | 모든 곳에서 접근 가능 |
| **private** | 사적인 | 해당 클래스/구조체 내부에서만 접근 가능 (기본값) |
| **protected** | 보호된 | 해당 클래스 내부 및 상속받은 자식 클래스에서 접근 가능 |
| **internal** | 내부의 | 같은 어셈블리(프로젝트) 내에서만 접근 가능 |

---

## 2. 상세 설명 및 예시

### 🟢 public

제한이 없습니다. 외부 클래스, 다른 프로젝트에서도 접근할 수 있습니다. 보통 외부로 노출할 API나 기능을 선언할 때 사용합니다.

### 🔴 private

가장 엄격합니다. 클래스 밖에서는 절대 보이지 않습니다. 객체의 상태를 보호하기 위해 필드(변수)를 선언할 때 주로 사용합니다.

### 🟡 protected

가족(상속 관계)에게만 공개합니다. 부모 클래스의 기능을 자식 클래스가 물려받아 사용하거나 재정의(Override)할 때 유용합니다.

### 🔵 internal

우리 팀(동일 프로젝트) 내에서만 공유합니다. 라이브러리 제작 시 내부 동작을 위해 필요하지만 사용자에게 노출하고 싶지 않은 클래스에 사용합니다.

---

## 3. 요약 및 권장 사항

1. **기본은 private:** 특별한 이유가 없다면 변수는 `private`으로 만드세요.  
2. **필요할 때만 public:** 외부에 꼭 알려줘야 하는 기능(메서드)만 `public`으로 엽니다.  
3. **상속은 protected:** 상속 구조에서 자식이 부모의 것을 써야 한다면 `protected`를 고려하세요.
