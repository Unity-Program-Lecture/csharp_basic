오늘의 목표는 **"프로그램을 꺼도 데이터가 사라지지 않게 파일로 저장하고, 다시 불러오는 법을 배운다"**입니다.

---

## 1. 파일 쓰기(File Write): "기록하기"
메모리에만 있는 데이터를 텍스트 파일(`.txt`)로 옮겨 적는 과정입니다.

### 💡 이 단어는 무슨 뜻인가요?
- **`File.WriteAllText`**: 파일 하나에 내용을 덮어씌워 기록합니다.
- **`File.AppendAllText`**: 기존 내용 뒤에 새로운 내용을 덧붙입니다. (로그용으로 적합)
- **`System.IO`**: 파일 관련 기능을 쓰기 위해 꼭 필요한 라이브러리입니다.

### 💻 실습 예제: 한 줄 일기장
**미션:** 사용자로부터 한 줄의 문장을 입력받아 `diary.txt` 파일에 저장해 보세요.

<details>
<summary>코드 보기</summary>

```csharp
using System;
using System.IO; // 파일 입출력을 위해 필수!

namespace Day15
{
    internal class Program
    {
        static void Main(string[] args)
        {
            string path = "diary.txt";
            
            Console.Write("오늘의 한 줄 일기: ");
            string content = Console.ReadLine();

            // 파일에 기록하기 (덮어쓰기)
            File.WriteAllText(path, content);
            
            Console.WriteLine("일기가 저장되었습니다!");
        }
    }
}
```

</details>

## 2. 파일 읽기(File Read): "불러오기"
파일에 저장된 텍스트를 읽어와서 프로그램의 변수에 담는 과정입니다.

### 💡 이 단어는 무슨 뜻인가요?
- **`File.ReadAllText`**: 파일의 전체 내용을 하나의 긴 문자열로 읽어옵니다.
- **`File.ReadAllLines`**: 파일의 내용을 한 줄씩 나누어 배열(`string[]`)로 읽어옵니다.
- **`File.Exists`**: 해당 파일이 실제로 존재하는지 확인합니다. (사고 방지!)

### 💻 실습 예제: 저장된 일기 불러오기
**미션:** `diary.txt` 파일이 있는지 확인하고, 그 내용을 읽어와 화면에 출력해 보세요.

<details>
<summary>코드 보기</summary>

```csharp
using System;
using System.IO;

namespace Day15
{
    internal class Program
    {
        static void Main(string[] args)
        {
            string path = "diary.txt";

            if (File.Exists(path)) // 파일이 있는지 먼저 확인!
            {
                string savedData = File.ReadAllText(path);
                Console.WriteLine("불러온 일기: " + savedData);
            }
            else
            {
                Console.WriteLine("저장된 일기가 없습니다.");
            }
        }
    }
}
```

</details>

## 4. 15일차 심화 미션: "캐릭터 세이브/로드 시스템"

**[미션 목표]**
몬스터 사냥 시스템의 전체 데이터를 파일로 저장하고 복구하는 로직을 설계합니다. 이를 통해 게임의 세이브 포인트와 데이터 영속성(Persistence)의 개념을 이해합니다.

---

### 1) 요구 사항

#### 1. 세이브 데이터 구성
* **상태 정보**: 플레이어의 이름, 레벨, 현재 체력, 공격력을 하나의 문자열로 결합하여 저장합니다. (예: `Player,5,100,25`)
* **인벤토리 정보**: `Dictionary`에 담긴 아이템과 개수를 한 줄씩 기록합니다.

#### 2. Save/Load 메서드 구현
* **SaveGame()**: 현재 캐릭터와 인벤토리 상태를 `SaveData.txt`에 기록합니다.
* **LoadGame()**: 파일의 데이터를 읽어와 쉼표(`,`)를 기준으로 쪼개어(`Split`) 캐릭터 객체의 값을 복구합니다.

#### 3. 세이브 포인트 시점
* 몬스터 사냥이 끝나거나 상점에서 아이템을 구매했을 때 자동으로 `SaveGame()`이 실행되도록 설계해 보세요.

---

### 2) 프로그래밍 힌트
* `string.Join(",", dataList)`를 사용하면 리스트의 내용을 쉼표로 연결할 수 있습니다.
* 읽어온 문자열을 다시 숫자로 바꿀 때는 `int.Parse()`를 사용하세요.
* 인벤토리 딕셔너리를 저장할 때는 `foreach`문을 돌며 `File.AppendAllText`를 사용하는 것이 편리합니다.
