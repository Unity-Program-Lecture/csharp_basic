# 🚀 유니티 엔진 시작하기: 입문자를 위한 핵심 가이드

유니티 엔진은 우리가 만든 C# 알고리즘이 실제로 살아 움직이는 '무대'입니다. 이 가이드는 프로그래밍 관점에서 유니티를 어떻게 다루어야 하는지 핵심만 콕 짚어 설명합니다.

---

## 1. 유니티의 5대 핵심 화면 (무대 뒤의 모습)

유니티 에디터는 크게 5개의 창으로 구성됩니다. 각 창의 역할을 기억하세요!

1. **Scene (장면 창)**: 게임 속 세상을 배치하는 **'도면'**입니다. 마우스로 물체를 옮기고 돌릴 수 있습니다.
2. **Game (게임 창)**: 플레이어가 실제로 보게 될 **'카메라 렌즈'** 화면입니다.
3. **Hierarchy (하이어라키/계층 창)**: 현재 무대에 올라와 있는 **'출연진 목록'**입니다. (Tree 구조)
4. **Project (프로젝트 창)**: 게임에 쓰일 모든 재료(대본, 소품, 음악)가 들어있는 **'창고'**입니다.
5. **Inspector (인스펙터/속성 창)**: 선택한 출연진의 **'상세 프로필'**입니다. 여기서 체력, 이름 등을 수정합니다.

---

## 2. 유니티의 기본 원리: "레고 블록(Component)"

유니티의 모든 물체는 **GameObject**라고 부릅니다. 이 빈 상자에 어떤 **Component(기능 블록)**를 끼우느냐에 따라 정체가 결정됩니다.

- **Transform**: 모든 물체가 가진 기본 블록 (위치, 회전, 크기).
- **Mesh Renderer**: 물체를 화면에 **'보이게'** 만드는 블록.
- **Rigidbody**: 물체에 **'무게와 물리'**를 주는 블록.
- **C# Script**: 우리가 만든 **'두뇌(알고리즘)'** 블록.

💡 **비유**: 빈 마네킹(GameObject)에 옷(Renderer)을 입히고, 심장(Rigidbody)을 넣고, 지능(Script)을 주입하는 것과 같습니다.

---

## 3. C# 스크립트 연결하기 (알고리즘 주입)

우리가 작성한 C# 코드가 작동하려면 반드시 다음 과정을 거쳐야 합니다.

1. **생성**: Project 창에서 우클릭 -> Create -> C# Script.
2. **작성**: 파일을 더블 클릭하여 코드를 씁니다 (Visual Studio).
3. **연결 (중요!)**: 작성한 파일을 Hierarchy에 있는 **GameObject 위로 드래그 앤 드롭**합니다.
    - *주의: 인스펙터 창에 스크립트가 컴포넌트로 붙어있어야만 실행됩니다!*

---

## 4. 반드시 알아야 할 단축키 (작업 속도 2배!)

- **Q (Hand)**: 화면 시점 이동
- **W (Move)**: 물체 이동 (화살표 드래그)
- **E (Rotate)**: 물체 회전
- **R (Scale)**: 물체 크기 조절
- **F (Focus)**: 선택한 물체로 카메라 즉시 이동 (미선택 시 하이어라키에서 더블클릭)
- **Ctrl + P**: 게임 시작 / 일시정지

---

## 5. 코딩 시작 전의 약속: MonoBehaviour

유니티에서 만드는 모든 스크립트는 기본적으로 `MonoBehaviour`라는 기능을 물려받습니다.

```csharp
public class MyAlgorithm : MonoBehaviour
{
    // 게임이 시작될 때 딱 한 번 실행 (초기화)
    void Start()
    {
        Debug.Log("무대에 등장했습니다!");
    }

    // 매 프레임마다 실행 (초초당 60~144번) - 길찾기, 이동 등
    void Update()
    {
        // 알고리즘이 실시간으로 작동하는 곳
    }
}
```
