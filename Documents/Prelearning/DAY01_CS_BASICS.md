# 📝 DAY 01: C# 프로그래밍의 시작과 변수 (2026.04.21)

오늘의 목표는 C#이라는 새로운 언어의 **'말하기(출력)'**와 **'담기(변수)'**를 마스터하는 것입니다. 프로그래밍은 컴퓨터에게 일을 시키는 '대화'의 과정입니다.

---

## 🔍 코드 독해 3원칙 (컴퓨터처럼 읽기)
복잡한 코드를 만났을 때 당황하지 말고 아래 세 가지 원칙을 기억하세요.

1. **위 ➜ 아래**: 컴퓨터는 위에서부터 한 줄씩 순서대로 읽습니다.
2. **오른쪽 ➜ 왼쪽 (`=` 기호)**: `=`은 "같다"가 아니라 **"담는다"**는 뜻입니다. 오른쪽의 결과를 왼쪽 상자에 집어넣으세요.
   - 예: `int a = 10;` (10이라는 숫자를 상자 a에 담아라!)
3. **안쪽 ➜ 바깥쪽 (괄호 `()`):** 괄호가 겹쳐 있다면 가장 안쪽의 명령부터 처리합니다.
   - 예: `Console.WriteLine(1 + 2);` (1+2를 먼저 계산하고, 그 결과를 출력해라!)

## [2교시] 코드의 집과 시작 버튼
C# 코드를 처음 보면 외계어 같지만, 사실 '울타리'와 '단추'로 이루어져 있습니다.

```csharp
using System; // 도구 상자를 가져옵니다.

namespace MyFirstConsole // 우리 집 주소입니다.
{
    internal class Program // 'Program'이라는 이름의 집(클래스)입니다.
    {
        // 컴퓨터가 프로그램을 실행할 때 가장 먼저 누르는 '시작 버튼'입니다.
        static void Main(string[] args) 
        {
            Console.WriteLine("안녕, C#!"); // 콘솔창에 글자를 출력합니다.
        }
    }
}
```

- **Class (집):** 모든 코드는 반드시 `class`라는 울타리 안에 보호받아야 합니다.
- **Main (시작점):** 프로그램의 엔진을 켜는 열쇠 구멍입니다. 무조건 여기서 시작합니다.

## [3교시] 변수(Variable): 데이터에 붙이는 이름표
컴퓨터 메모리 어딘가에 저장된 데이터에 우리가 부르기 쉬운 **'이름표(변수명)'**를 붙이는 것입니다. 이름표를 보고 데이터를 찾아가서 읽거나 새 데이터로 바꿀 수 있습니다.

### 🏷️ 핵심 데이터 타입 4인방 (이름표의 종류)
데이터의 성격에 따라 붙일 수 있는 이름표의 종류(타입)가 다릅니다.

| 타입 | 비유 | 설명 | 예시 |
| :--- | :--- | :--- | :--- |
| **int** | 정수 이름표 | 소수점 없는 **숫자**에 붙입니다. | 10, -5, 0 |
| **float** | 실수 이름표 | **소수점**이 있는 숫자에 붙입니다. (뒤에 `f` 필수) | 3.14f, 0.5f |
| **string** | 문장 이름표 | 큰따옴표로 감싼 **글자들**에 붙입니다. | "Hello", "C#" |
| **bool** | 스위치 이름표 | **참/거짓** 딱 두 가지 상태에만 붙입니다. | true, false |

### 💻 실습 예제: 내 캐릭터 정보에 이름표 붙이기
아래 코드를 타이핑하며 데이터에 이름표가 붙는 과정을 느껴보세요.

```csharp
// 1. 데이터에 이름표 붙이기 (오른쪽 값을 왼쪽 이름표로 부르겠다!)
string heroName = "전사 가우스"; // "전사 가우스"라는 글자에 heroName 이름표를 붙임
int level = 1;                 // 1이라는 숫자에 level 이름표를 붙임
float speed = 5.5f;            // 5.5라는 숫자에 speed 이름표를 붙임
bool isAlive = true;           // true라는 상태에 isAlive 이름표를 붙임

// 2. 이름표로 데이터 찾아 쓰기 (위에서 아래로!)
Console.WriteLine("캐릭터 이름: " + heroName);
Console.WriteLine("현재 레벨: " + level);
Console.WriteLine("이동 속도: " + speed + "m/s");
Console.WriteLine("생존 여부: " + isAlive);
```

## [4교시] 정리 및 퀴즈
- **주석(`//`):** 컴퓨터는 무시하고 사람만 읽는 '메모'입니다.
- **세미콜론(`;`):** C# 문장의 마침표입니다. 잊으면 컴퓨터가 문장을 이해하지 못합니다.
