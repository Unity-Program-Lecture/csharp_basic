# 🚀 16일차: 클래스의 완성 그리고 넓은 세상 (Property & 2D Array)

오늘의 목표는 "**데이터를 안전하게 지키는 프로퍼티(Property)를 익히고, 2차원 배열을 통해 평면 공간을 다루는 법을 배운다**"입니다.

---

## 1. 프로퍼티(Property): "안전한 창구"
변수를 `public`으로 두면 아무나 값을 바꿀 수 있어 위험합니다. 프로퍼티는 변수를 보호하면서도 외부에서 사용하기 편하게 해주는 '안전 창구'입니다.

### 💡 왜 프로퍼티를 쓰나요?
- **검증**: "체력(HP)을 음수로 바꿀 수 없게 해줘!" 같은 규칙을 넣을 수 있습니다.
- **가독성**: 메소드(`GetHp()`, `SetHp()`)보다 변수처럼 사용하기 훨씬 편합니다.

### 💻 실습 예제: 체력 보호 시스템
**미션:** HP가 0 미만으로 내려가지 않도록 막는 프로퍼티를 만들어 보세요.

<details>
<summary>코드 보기</summary>

```csharp
class Player
{
    private int hp = 100;

    public int HP
    {
        get { return hp; }
        set 
        { 
            if (value < 0) hp = 0; // 음수 방지!
            else hp = value;
        }
    }
}
```

</details>

## 2. 2차원 배열: "바둑판 모양의 바구니"
지금까지 배운 배열이 일렬(1D)이었다면, 2차원 배열은 가로와 세로가 있는 평면(Grid)입니다. 게임 맵이나 바둑판을 만들 때 필수입니다.

### 💻 실습 예제: 간단한 미로 데이터
**미션:** 2차원 배열을 사용하여 3x3 크기의 맵 데이터를 만들고 이중 `for`문으로 출력해 보세요.

<details>
<summary>코드 보기</summary>

```csharp
int[,] map = {
    { 1, 1, 1 },
    { 1, 0, 1 },
    { 1, 1, 1 }
};

for (int y = 0; y < 3; y++)
{
    for (int x = 0; x < 3; x++)
    {
        Console.Write(map[y, x] == 1 ? "■ " : "□ ");
    }
    Console.WriteLine();
}
```

</details>

## 3. 팁: `StringBuilder`
문자열(`string`)을 `+` 기호로 너무 많이 합치면 컴퓨터가 힘들어합니다. 문자열을 아주 많이 합쳐야 할 때는 '문자열 전용 건설 현장'인 `StringBuilder`를 사용하세요.
