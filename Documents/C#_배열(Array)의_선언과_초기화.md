# C# 기초: 배열(Array)의 선언과 초기화

C#에서 **배열**은 동일한 타입의 데이터를 메모리에 연속적으로 저장하는 가장 기본적인 자료구조입니다.

## 1\. 배열의 선언

어떤 종류의 데이터를 담을지 정의합니다. 타입 뒤에 `[]`를 붙여 선언합니다.

``` csharp
int[] scores;    // 정수형 배열

string[] names;  // 문자열형 배열
```

## 2. 배열의 초기화

`new` 키워드를 사용해 실제 데이터를 담을 공간을 만듭니다.

### 2.1 크기만 먼저 정하기

특정 크기만큼 빈 공간(기본값 0 등)을 만듭니다.

``` csharp
int[] numbers = new int[3]; // 3칸짜리 공간 생성

numbers[0] = 10;

numbers[1] = 20;

numbers[2] = 30;
```

### 2.2 선언과 동시에 값 넣기

데이터를 바로 나열하여 생성합니다.

``` csharp
// 방법 1: 가장 명확한 표현

int[] grades = new int[] { 90, 85, 70 };

// 방법 2: 가장 간결한 표현

int[] ages = { 25, 30, 22 };
```
## 3. 핵심 특징 (꼭 기억하세요!)

- **0번부터 시작**: 첫 번째 칸의 번호(인덱스)는 0입니다.  
- **고정된 크기**: 한 번 만든 배열은 칸을 늘리거나 줄일 수 없습니다.  
- **Length**: 배열의 전체 칸수를 알고 싶을 때 `배열명.Length`를 사용합니다.
``` csharp
int[] myArr = { 1, 2, 3 };

Console.WriteLine(myArr.Length); // 3 출력  
```
