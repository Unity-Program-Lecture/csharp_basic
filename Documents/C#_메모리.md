# 🚀 특별편: C# 메모리의 비밀 (스택, 힙, 그리고 리모컨)

C#을 배우다 보면 "값 타입은 뭐고 참조 타입은 뭐지?", "스택과 힙은 또 뭐야?" 하는 혼란이 찾아옵니다. 이 실타래를 풀지 못하면 나중에 배우는 객체지향의 핵심인 **클래스**와 **메모리 관리**에서 길을 잃기 쉽습니다.

오늘 이 문서 하나로 C# 메모리의 지도를 머릿속에 그려봅시다!

---

## 1. 데이터의 두 가지 형태: [값] vs [참조]

C#의 모든 데이터는 두 가지 방식 중 하나로 다뤄집니다.

### 🍎 값 타입 (Value Type): "내 손안의 사과"
- **종류**: `int`, `float`, `bool`, `struct`, `enum` 등
- **설명**: 변수라는 상자 안에 **진짜 데이터**(**값**)가 직접 들어있습니다.
- **복사**: 친구에게 사과를 주면, 똑같은 사과가 하나 더 생겨서 전달됩니다. 원본 사과를 한 입 베어 물어도 친구의 사과에는 아무런 변화가 없습니다.

### 🎮 참조 타입 (Reference Type): "내 손안의 리모컨"
- **종류**: `class`, `string`, `array`, `interface`, `object` 등
- **설명**: 변수라는 상자 안에는 진짜 물건이 아니라, 물건이 있는 주소가 적힌 **리모컨**이 들어있습니다. 진짜 물건(객체)은 메모리의 넓은 공간(힙)에 따로 있습니다.
- **복사**: 친구에게 리모컨을 주면, 친구는 **똑같은 물건**(**TV**)을 조종하게 됩니다. 친구가 리모컨으로 채널을 돌리면 내가 보는 화면도 바뀝니다.

---

## 2. 메모리의 두 구역: [스택] vs [힙]

컴퓨터는 데이터를 효율적으로 관리하기 위해 메모리를 두 구역으로 나눕니다.

### 🛠️ 스택 (Stack): "개인 작업대"
- **특징**: 아주 빠르고 정교하게 관리됩니다.
- **역할**: 현재 실행 중인 메소드 안에서 쓰이는 **지역 변수**들이 놓이는 곳입니다.
- **수명**: 메소드가 끝나면 작업대 위의 모든 물건(사과든 리모컨이든)은 **순식간에 자동으로 치워집니다.**

### 📦 힙 (Heap): "공용 창고"
- **특징**: 공간이 넓지만, 물건을 찾거나 치우는 데 시간이 좀 걸립니다.
- **역할**: `new` 키워드로 만들어진 **진짜 물건**(**객체**)들이 보관되는 곳입니다.
- **수명**: 작업대가 치워져도 창고의 물건은 그대로 남습니다. 아무도 이 물건을 조종할 리모컨을 가지고 있지 않을 때, **청소부**(**GC: Garbage Collector**)가 와서 수거해갑니다.

---

## 3. 필드(Field)는 어디에 저장될까?

많은 사람들이 "값 타입은 스택, 참조 타입은 힙"이라고 오해합니다. 하지만 정답은 이렇습니다.

> **"변수는 자기가 선언된 위치(부모)를 따라간다."**

1. **메소드 안의 변수**: 부모가 메소드(작업대)이므로 **스택**에 저장됩니다.
2. **클래스의 필드**: 부모가 클래스 객체(물건)이므로, 객체와 함께 **힙**에 저장됩니다. (객체라는 큰 상자 안에 쏙 들어가 있는 셈이죠.)

---

## 4. Boxing & Unboxing: "선물 포장"

가끔 사과(값 타입)를 창고(힙)에 보관해야 할 때가 있습니다.

- **Boxing (박싱)**: 사과를 상자에 담아 포장해서 창고로 보내는 과정입니다. (`int` -> `object`)
- **Unboxing (언박싱)**: 창고에서 상자를 가져와 포장을 뜯고 다시 사과를 꺼내는 과정입니다. (`object` -> `int`)
- **주의**: 포장을 하고 뜯는 데는 비용(시간)이 듭니다. 너무 자주 하면 프로그램이 느려집니다!

## 💻 실습 예제: 메모리 동작 확인하기

**미션:** 값 타입(int)과 참조 타입(class)의 변수를 복사했을 때, 한쪽의 값을 변경하면 다른 쪽이 어떻게 변하는지 확인하여 메모리 동작 원리를 이해해 보세요.

<details>
<summary>코드 보기</summary>

```csharp
using System;

namespace MemoryStudy
{
    // 참조 타입 (리모컨으로 조종할 TV)
    class Monster { public int hp; }

    internal class Program
    {
        static void Main(string[] args)
        {
            // 1. 값 타입 실습 (사과 복사)
            int apple1 = 10;
            int apple2 = apple1; // 사과가 하나 더 생김
            apple2 = 20;
            Console.WriteLine($"apple1: {apple1}, apple2: {apple2}"); // 결과: 10, 20 (서로 다름)

            // 2. 참조 타입 실습 (리모컨 복사)
            Monster m1 = new Monster(); // 창고에 몬스터 생성, m1은 리모컨
            m1.hp = 50;
            
            Monster m2 = m1; // 리모컨만 복사 (같은 몬스터를 가리킴)
            m2.hp = 0;
            
            Console.WriteLine($"m1 HP: {m1.hp}, m2 HP: {m2.hp}"); // 결과: 0, 0 (둘 다 바뀜!)
        }
    }
}
```

</details>
