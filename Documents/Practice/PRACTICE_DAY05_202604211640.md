# 📝 [연습문제] Day 05: 배열과 실무 응용

**목표**: 여러 데이터를 한 번에 관리하는 배열(Array)과 게임 로직을 구현합니다.

1. **[배열선언]** 숫자 5개를 담을 수 있는 `int[] scores` 배열을 만드세요.
2. **[값넣기]** 배열의 첫 번째 칸에 100을, 마지막 칸에 50을 저장하세요.
3. **[출력]** `foreach`문을 사용하여 배열의 모든 요소를 출력하세요.
4. **[검색]** 배열 안에서 가장 큰 숫자(최댓값)를 찾는 코드를 작성하세요.
5. **[평균]** 5명의 성적 배열을 만들고, 전체 평균을 구하세요.
6. **[문자열배열]** 인벤토리 아이템 이름 3개를 담는 배열을 만들고 출력하세요.
7. **[랜덤치명타]** 1부터 100까지 랜덤 숫자를 뽑아, 20 이하가 나오면 "치명타!"를 출력하세요.
8. **[가위바위보]** 사용자로부터 가위(0), 바위(1), 보(2)를 입력받아 컴퓨터(랜덤)와 승부하는 코드를 작성하세요.
9. **[배열뒤집기]** `{1, 2, 3, 4, 5}` 배열의 순서를 거꾸로 바꾸어 출력하세요.
10. **[종합미션]** 크기가 5인 `Monster` 배열을 만들고 각각 다른 이름을 부여한 뒤, 반복문을 통해 모든 몬스터가 한 번씩 공격하는 코드를 작성하세요.
