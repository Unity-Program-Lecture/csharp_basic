# 📝 [연습문제] Day 10: 2주차 종합 미션 (시스템 설계)

**목표**: 2주간 배운 객체지향 문법과 자료구조를 결합하여, 실제 게임 엔진에서도 작동 가능한 수준의 아이템/전투 시스템 로직을 완성합니다.

1. **[다형성]** `List<Item>`이라는 하나의 바구니에 `Potion` 객체와 `Weapon` 객체를 동시에 담을 수 있는 근거는 무엇인지 '상속'의 관점에서 설명하세요.
2. **[인터페이스]** `IUseable` 인터페이스를 상속받은 클래스가 반드시 구현해야 하는 메소드의 이름과 특징을 적어보세요.
3. **[검색 로직]** `List<Item>`에서 이름이 "빨간포션"인 아이템을 찾기 위해 `foreach`문과 `if`문을 어떻게 조합해야 하는지 의사코드(Pseudo-code)로 작성하세요.
4. **[아이템 제거]** 리스트에서 아이템을 사용할 때, `potion.Count--`를 하는 것과 `list.Remove(potion)`를 하는 것의 차이점은 무엇인가요?
5. **[자료구조 선택]** 인벤토리에서 아이템을 이름으로 검색할 때, `List`보다 `Dictionary<string, Item>`이 더 유리한 이유는 무엇인가요?
6. **[추상 클래스]** `Item` 클래스를 직접 생성(new Item())하지 못하게 막고 설계도로만 쓰게 하려면 클래스 앞에 어떤 키워드를 붙여야 하나요?
7. **[생성자 활용]** 아이템을 생성할 때 이름과 개수를 즉시 설정할 수 있도록 부모 클래스(`Item`)에 생성자를 정의해 보세요.
8. **[상태 출력]** 인벤토리에 있는 모든 아이템의 이름과 현재 수량을 한 줄씩 출력하는 `ShowInventory()` 메소드를 작성해 보세요.
9. **[예외 처리]** `UseItem(name)` 실행 시, 인벤토리에 해당 이름의 아이템이 없을 경우 "아이템을 찾을 수 없습니다"라는 메시지를 출력하도록 설계해 보세요.
10. **[종합 미션 설계]** 사용자가 "포션"을 사용하면 체력이 20 회복되고, "무기"를 사용하면 공격력이 5 상승하는 로직을 인터페이스의 `Use()` 메소드 안에 각각 어떻게 다르게 구현할지 구상해 보세요.
