# 📝 [연습문제] Day 06: 프로퍼티와 인터페이스

**목표**: 데이터를 안전하게 보호하는 프로퍼티(Property)와 객체의 기능 규격을 정의하는 인터페이스(Interface)를 익힙니다.

1. **[프로퍼티]** `Player` 클래스에 `private int hp` 변수를 만들고, 이를 읽고 쓸 수 있는 `HP` 프로퍼티를 만드세요.
2. **[데이터 보호]** `set` 안에서 값이 0 미만으로 들어오면 0으로 저장되도록 `Level` 프로퍼티를 제어해 보세요.
3. **[자동 구현]** 로직 없이 간단하게 사용할 수 있는 `string Name` 자동 구현 프로퍼티를 선언하세요.
4. **[읽기 전용]** `Gold` 변수를 읽을 수는 있지만, 외부에서 직접 수정은 불가능한(private set) 프로퍼티를 만드세요.
5. **[인터페이스]** "데미지를 입을 수 있음"을 뜻하는 `IDamageable` 인터페이스를 만들고, `void TakeDamage(int amount)` 메소드를 선언하세요.
6. **[구현]** `Monster` 클래스가 `IDamageable` 인터페이스를 상속받아 실제 데미지 감소 로직을 구현하게 하세요.
7. **[다중 구현]** 한 클래스가 `IMovable`(이동)과 `IAttackable`(공격)이라는 두 개의 인터페이스를 동시에 상속받아 기능을 구현해 보세요.
8. **[인터페이스 타입]** `IDamageable` 타입의 변수에 `Player` 객체를 담고 `TakeDamage` 메소드를 실행해 보세요.
9. **[상호작용]** `IUsable` 인터페이스를 구현한 `Potion` 클래스를 만들고, `Use()` 메소드 호출 시 "체력이 회복되었습니다"를 출력하세요.
10. **[종합미션]** `IDamageable` 타입의 배열을 만들어 `Player`, `Monster`, `WoodenBox`를 각각 담은 뒤, 반복문을 통해 모든 대상에게 동일하게 10의 데미지를 입히는 로직을 작성하세요.
