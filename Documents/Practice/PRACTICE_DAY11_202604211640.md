# 📝 [연습문제] Day 11: 예외 처리 (Exception Handling)

**목표**: 프로그램 실행 중 발생하는 예기치 못한 사고(예외)를 이해하고, try-catch-finally 문법을 통해 프로그램의 비정상 종료를 방지하는 법을 익힙니다.

1. **[개념]** 컴파일 시점에 발생하는 '에러(Error)'와 프로그램 실행 중에 발생하는 '예외(Exception)'의 차이점을 설명하세요.
2. **[기본 문법]** `try`, `catch`, `finally` 각 블록이 수행하는 역할을 한 문장씩 정리해 보세요.
3. **[예외 잡기]** 0으로 나누기 연산을 시도할 때 발생하는 예외의 이름은 무엇인가요?
4. **[형식 예외]** 문자열 "Hello"를 `int.Parse()`로 숫자로 바꾸려 할 때 발생하는 예외의 이름은 무엇인가요?
5. **[안전한 종료]** 예외 발생 여부와 상관없이 파일 닫기나 로그 저장처럼 '무조건 실행'되어야 하는 코드는 어느 블록에 작성해야 하나요?
6. **[예외 던지기]** 개발자가 특정 조건에서 의도적으로 사고를 발생시킬 때 사용하는 키워드는 무엇인가요?
7. **[참조 예외]** 유니티에서 가장 자주 보게 될 예외로, 값이 비어있는(null) 리모컨을 사용하려 할 때 발생하는 예외의 이름은 무엇인가요?
8. **[다중 catch]** 하나의 `try` 블록 뒤에 여러 개의 `catch` 블록을 사용할 수 있습니다. 이때 가장 범위가 넓은 `catch (Exception e)`는 어느 위치(처음/마지막)에 두는 것이 좋은가요?
9. **[메시지 출력]** `catch (Exception e)`에서 에러의 구체적인 이유(메시지)를 출력하고 싶을 때 사용하는 속성은 무엇인가요?
10. **[종합미션]** 사용자로부터 인덱스 번호를 입력받아 배열의 값을 출력하는 코드를 작성하세요. 만약 배열 범위를 벗어난 번호를 입력하면 "잘못된 번호입니다"를, 숫자가 아닌 문자를 입력하면 "숫자만 입력하세요"를 출력하도록 설계해 보세요.
