# 📝 [연습문제] Day 12: 델리게이트와 이벤트

**목표**: 메소드를 변수처럼 취급하는 델리게이트의 원리를 이해하고, 객체 간의 결합도를 낮추는 이벤트 시스템을 설계합니다.

1. **[개념]** '델리게이트(Delegate)'라는 단어의 사전적 의미와 프로그래밍에서의 역할을 '메소드 바구니' 비유를 들어 설명하세요.
2. **[선언]** 정수 두 개를 매개변수로 받고 반환값이 없는 메소드들을 담을 수 있는 `delegate void MyDelegate(int a, int b);`를 선언해 보세요.
3. **[할당]** 선언된 델리게이트 변수에 특정 메소드를 연결하거나 갈아 끼울 때 사용하는 문법을 작성하세요.
4. **[이벤트 선언]** 클래스 외부에서 직접 호출할 수는 없지만 구독은 가능한 안전한 알림 장치인 '이벤트'를 선언할 때 사용하는 키워드는 무엇인가요?
5. **[구독]** 특정 이벤트에 기능을 추가할 때 사용하는 기호(`+=`)와 더 이상 알림을 받지 않기 위해 제거할 때 사용하는 기호를 적어보세요.
6. **[실행]** 이벤트에 등록된 모든 구독자에게 소식을 알릴 때 사용하는 메소드는 무엇인가요? (힌트: `?.Invoke()`)
7. **[Action/Func]** C#에서 미리 만들어 제공하는 델리게이트 중, 반환값이 없는 메소드에 주로 사용하는 것은 무엇인가요?
8. **[람다식]** `delegate`를 별도로 정의하지 않고 `() => { ... }` 형태로 간결하게 기능을 전달하는 방식의 이름을 무엇이라 하나요?
9. **[안전성]** 델리게이트와 비교했을 때, 이벤트가 가진 '클래스 외부 호출 불가'라는 특성이 프로그램의 안정성에 어떤 도움을 주는지 설명하세요.
10. **[종합미션]** `Monster` 클래스가 죽었을 때(`OnDead`), UI 클래스는 "사망 UI 출력", 사운드 클래스는 "비명 소리 재생"을 수행하도록 이벤트를 설계하고 구독하는 코드를 작성하세요.
