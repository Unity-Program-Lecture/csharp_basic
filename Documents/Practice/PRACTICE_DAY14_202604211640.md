# 📝 [연습문제] Day 14: 열거형(Enum)과 구조체(Struct)

**목표**: 숫자에 이름을 붙여 가독성을 높이는 열거형의 활용법을 익히고, 클래스와 구조체의 메모리 동작 차이(값 형식 vs 참조 형식)를 이해합니다.

1. **[열거형 정의]** 게임 아이템의 등급(일반, 희귀, 영웅, 전설)을 나타내는 `ItemGrade` 열거형을 선언해 보세요.
2. **[형변환]** 열거형 변수에 담긴 이름이 아닌 '숫자 번호'를 출력하고 싶을 때 사용하는 문법은 무엇인가요?
3. **[가독성]** `if (status == 2)`라는 코드보다 `if (status == State.Attack)`라는 코드가 더 좋은 이유를 '실수 방지' 측면에서 설명하세요.
4. **[구조체 선언]** 2D 게임의 좌표를 저장하기 위한 `struct Point`를 만드세요. 내부에 정수형 변수 `x`와 `y`를 포함해야 합니다.
5. **[메모리 위치]** 구조체(Struct)는 메모리의 어느 영역(Stack/Heap)에 저장되나요? 클래스와 비교하여 답하세요.
6. **[복사 특징]** 구조체 변수를 다른 변수에 대입했을 때 발생하는 현상을 '시험지 복사' 비유를 들어 설명해 보세요.
7. **[비밀 확인]** 우리가 자주 쓰는 `int`, `float`, `bool`은 사실 클래스일까요, 구조체일까요?
8. **[클래스의 성격]** `string`은 데이터 크기가 가변적입니다. 이 때문에 구조체가 아닌 '이것' 형식으로 만들어졌습니다. '이것'은 무엇인가요?
9. **[제네릭 제약]** 제네릭 클래스에서 "값 형식(구조체)만 재료로 쓰겠다"라고 제한을 걸 때 사용하는 문지기(`where`) 코드를 작성하세요.
10. **[종합미션]** 캐릭터의 직업(`Job` 열거형)과 좌표(`Position` 구조체)를 멤버로 가지는 `CharacterInfo` 구조체를 만드세요. 그리고 이를 생성하여 값을 넣고 출력하는 로직을 작성해 보세요.
