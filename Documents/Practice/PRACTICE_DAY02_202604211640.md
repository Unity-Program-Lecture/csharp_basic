# 📝 [연습문제] Day 02: 제어문 (조건문과 반복문)

**목표**: 프로그램의 흐름을 바꾸는 갈림길(if)과 반복(for/while)을 익힙니다.

1. **[조건]** 점수 상자 `score`가 60점 이상이면 "합격", 아니면 "불합격"을 출력하세요.
2. **[홀짝]** 입력받은 숫자가 짝수면 "짝", 홀수면 "홀"을 출력하세요. (힌트: `% 2 == 0`)
3. **[반복]** 1부터 10까지 숫자를 한 줄씩 출력하는 for문을 작성하세요.
4. **[구구단]** 2단을 출력하는 코드를 작성하세요. (2 * 1 = 2 ... 2 * 9 = 18)
5. **[누적]** 1부터 100까지의 합을 구해 출력하는 코드를 작성하세요.
6. **[무한루프]** `while`문을 사용하여 사용자가 0을 입력할 때까지 계속 숫자를 입력받는 코드를 작성하세요.
7. **[스위치]** `int weaponType`이 1이면 "검", 2이면 "활", 3이면 "지팡이"를 출력하는 switch문을 작성하세요.
8. **[다중조건]** 나이가 10세 이상이고 20세 미만이면 "청소년"을 출력하는 코드를 작성하세요. (힌트: `&&`)
9. **[역순]** 10부터 1까지 거꾸로 출력하는 코드를 작성하세요.
10. **[미션]** 몬스터의 HP가 100입니다. 공격할 때마다 HP가 15씩 줄어들며, HP가 0 이하가 되면 "처치 완료"를 출력하는 코드를 작성하세요.
