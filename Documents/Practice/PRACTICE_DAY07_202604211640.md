# 📝 [연습문제] Day 07: 컬렉션 (List와 Dictionary)

**목표**: 데이터의 개수가 유동적인 상황에서 List를 활용하고, 키(Key)를 통해 데이터를 빠르게 찾는 Dictionary의 사용법을 익힙니다.

1. **[네임스페이스]** List와 Dictionary를 사용하기 위해 코드 최상단에 추가해야 하는 `using` 문장을 작성하세요.
2. **[리스트 생성]** 문자열(string) 데이터를 담을 수 있는 `monsterList`라는 이름의 리스트를 생성하세요.
3. **[데이터 추가]** 생성한 `monsterList`에 "슬라임", "오크", "고블린" 세 가지 데이터를 차례대로 추가하세요.
4. **[리스트 삭제]** `monsterList`에서 1번 인덱스에 있는 데이터를 삭제하고, 삭제 후 "고블린"의 인덱스 번호가 몇 번이 되는지 적어보세요.
5. **[리스트 개수]** 리스트에 담긴 데이터의 총 개수를 출력할 때 사용하는 속성(Property)은 무엇인가요?
6. **[딕셔너리 생성]** 키(Key)는 아이템 이름(string), 값(Value)은 가격(int)을 담는 `itemPrices` 딕셔너리를 생성하세요.
7. **[데이터 삽입]** 딕셔너리에 "물약"은 50원, "칼"은 150원을 저장하는 코드를 작성하세요.
8. **[데이터 수정]** 기존에 저장된 "물약"의 가격을 100원으로 변경하는 코드를 작성하세요.
9. **[안전한 검사]** 딕셔너리에 "방패"라는 키(Key)가 있는지 확인하고, 있을 때만 가격을 출력하는 코드를 작성하세요. (힌트: `ContainsKey`)
10. **[종합미션]** `Dictionary<string, int>`를 활용해 학생의 이름과 점수를 관리하는 성적표를 만드세요. 3명의 점수를 입력받아 저장한 뒤, `foreach`문을 사용하여 모든 학생의 이름과 점수를 한 줄씩 출력하세요.
