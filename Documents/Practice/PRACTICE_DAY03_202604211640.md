# 📝 [연습문제] Day 03: 메소드와 클래스

**목표**: 기능을 분리(메소드)하고 객체의 설계도(클래스)를 만듭니다.

1. **[메소드]** 두 숫자를 더해서 결과를 돌려주는 `Add(int a, int b)` 함수를 만드세요.
2. **[출력함수]** 이름을 입력받아 "안녕하세요, [이름]님!"을 출력하는 `Greet(string name)` 함수를 만드세요.
3. **[랜덤]** 1부터 6까지의 주사위 숫자를 돌려주는 `RollDice()` 함수를 만드세요.
4. **[클래스]** `Player` 클래스를 만들고, 이름(string)과 체력(int) 변수를 넣으세요.
5. **[인스턴스]** 위에서 만든 `Player` 클래스로 내 캐릭터 `p1`을 생성하고 이름을 "용사"로 지어주세요.
6. **[기능추가]** `Player` 클래스 안에 체력을 10 회복하는 `Heal()` 메소드를 만드세요.
7. **[접근제한]** `Player`의 체력 상자를 `private`으로 만들고, 체력을 확인할 수 있는 `GetHP()` 메소드를 만드세요.
8. **[매개변수]** 특정 데미지 만큼 체력을 깎는 `TakeDamage(int damage)` 메소드를 만드세요.
9. **[여러 객체]** `Player` 두 명을 만들어 서로 다른 이름을 부여하고 출력하세요.
10. **[종합]** `Monster` 클래스를 만들고, 공격력(atk)을 반환하는 `GetAtk()` 메소드를 구현하여 플레이어와 전투하는 로직을 간단히 짜보세요.
