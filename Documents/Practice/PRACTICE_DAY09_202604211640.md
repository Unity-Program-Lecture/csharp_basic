# 📝 [연습문제] Day 09: 스택(Stack)과 큐(Queue)

**목표**: 데이터의 입출력 순서가 정해진 자료구조인 Stack(후입선출)과 Queue(선입선출)의 원리를 이해하고 실제 게임 로직에 적용합니다.

1. **[개념]** Stack의 특징인 'LIFO'와 Queue의 특징인 'FIFO'가 각각 무엇의 약자인지 쓰고, 실생활의 예시를 하나씩 들어보세요.
2. **[스택 선언]** 정수 데이터를 담을 수 있는 `Stack<int> numbers`를 생성하고 숫자 10, 20, 30을 순서대로 넣는 코드를 작성하세요.
3. **[스택 추출]** 위에서 만든 스택에서 `Pop()`을 한 번 실행했을 때 나오는 숫자는 무엇이며, 남은 데이터는 무엇인지 적어보세요.
4. **[스택 확인]** 데이터를 삭제하지 않고 맨 위에 무엇이 있는지만 확인하고 싶을 때 사용하는 메소드는 무엇인가요?
5. **[큐 선언]** 문자열 데이터를 담을 수 있는 `Queue<string> messageQueue`를 생성하고 "A", "B", "C"를 순서대로 넣는 코드를 작성하세요.
6. **[큐 추출]** 위에서 만든 큐에서 `Dequeue()`를 한 번 실행했을 때 나오는 문자는 무엇이며, 남은 데이터는 무엇인지 적어보세요.
7. **[응용]** 웹 브라우저의 '뒤로 가기' 기능을 구현하려고 합니다. Stack과 Queue 중 어떤 자료구조를 사용하는 것이 적절할까요?
8. **[응용]** 프린터의 인쇄 대기 목록을 관리하려고 합니다. Stack과 Queue 중 어떤 자료구조를 사용하는 것이 적절할까요?
9. **[반복문]** `while`문과 `Count` 속성을 사용하여 큐 안에 있는 모든 데이터를 하나씩 꺼내어 출력하는 코드를 작성해 보세요.
10. **[종합미션]** '카드 덱' 시스템을 만드세요. `Stack<string>`에 카드 이름 3개를 넣고, 사용자가 "뽑기"를 입력할 때마다 카드를 한 장씩 오픈하다가 카드가 모두 떨어지면 "덱이 비었습니다"를 출력하는 로직을 작성하세요.
