# 📝 [연습문제] Day 01: 변수와 데이터 타입

**목표**: 데이터에 알맞은 이름표(변수)를 붙여 관리하는 법을 익힙니다.

1. **[출력]** 자신의 이름을 콘솔창에 출력하는 코드를 작성하세요.
2. **[정수]** 나이 데이터 20에 `age`라는 이름표를 붙이고 출력하세요.
3. **[실수]** 이동 속도 5.5에 `moveSpeed`라는 이름표를 붙이고 출력하세요. (힌트: float 뒤에는 f를 붙입니다.)
4. **[문자열]** 좋아하는 게임 이름에 `gameTitle`이라는 이름표를 붙이고 출력하세요.
5. **[논리]** "게임을 실행 중인가?"라는 상태(true)에 `isGaming`이라는 이름표를 붙이고 출력하세요.
6. **[덧셈]** `int a = 10;`, `int b = 20;` 두 이름표가 가리키는 값을 더한 결과를 출력하세요.
7. **[교환]** `x = 10`, `y = 20` 데이터가 있습니다. 두 데이터의 이름표를 서로 바꾸어 보세요. (힌트: 잠시 데이터를 옮겨둘 `temp` 이름표가 필요합니다.)
8. **[연결]** "나의 레벨은 "이라는 글자와 `level = 1` 이름표를 합쳐서 "나의 레벨은 1"이라고 출력하세요.
9. **[오류찾기]** `int score = 95.5f;` 코드가 에러 나는 이유를 이름표의 종류(타입) 관점에서 설명하고 수정하세요.
10. **[종합]** 이름(string), 레벨(int), 생존여부(bool) 데이터에 각각 이름표를 붙이고 한 줄씩 출력하는 캐릭터 프로필 코드를 작성하세요.
