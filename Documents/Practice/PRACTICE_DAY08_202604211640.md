# 📝 [연습문제] Day 08: 제네릭 (Generics)

**목표**: 데이터 타입에 관계없이 동작하는 '만능 틀'인 제네릭의 원리를 이해하고, 메소드와 클래스에 적용하는 법을 익힙니다.

1. **[개념]** 제네릭에서 사용하는 `<T>` 기호의 의미는 무엇인지 '붕어빵 틀' 비유를 들어 설명해 보세요.
2. **[메소드 선언]** 어떤 타입이든 인자로 받아 그대로 출력해주는 제네릭 메소드 `public void Show<T>(T data)`를 선언해 보세요.
3. **[클래스 선언]** 한 가지 데이터를 안전하게 보관할 수 있는 제네릭 클래스 `class Storage<T>`의 기본 구조를 작성하세요.
4. **[인스턴스화]** 위에서 만든 `Storage<T>` 클래스를 사용하여 정수(int)를 저장할 수 있는 `intStore` 객체를 생성해 보세요.
5. **[필드 활용]** 제네릭 클래스 내부에서 `T` 타입의 변수 `data`를 선언하고, 이를 생성자를 통해 초기화하는 코드를 작성하세요.
6. **[반환 타입]** 제네릭 클래스에서 보관 중인 데이터를 밖으로 돌려주는 메소드 `public T GetData()`를 작성해 보세요.
7. **[복수 제네릭]** 두 가지 서로 다른 타입을 동시에 사용하는 제네릭 클래스 `class Pair<T, U>`를 선언해 보세요.
8. **[장점]** `object` 타입을 사용하는 것보다 제네릭을 사용하는 것이 성능과 안전성 면에서 왜 유리한지 한 문장으로 적어보세요.
9. **[타입 추론]** `Swap<int>(ref a, ref b)`라고 쓰는 대신 `Swap(ref a, ref b)`라고만 써도 컴퓨터가 타입을 알 수 있는 이유를 설명해 보세요.
10. **[종합미션]** 몬스터 객체나 아이템 객체 등 어떤 것이든 담을 수 있는 `Inventory<T>` 클래스를 만드세요. 내부에 `T` 타입의 배열을 가지고 있으며, 특정 인덱스에 물건을 넣고 빼는 기능을 구현해 보세요.
