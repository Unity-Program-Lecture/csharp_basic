# DAY 06: 캐릭터, 배경, 최종 기획 발표

오늘은 캐릭터와 배경 설정을 정리하고, 6일 동안 작성한 문서를 하나의 기획 초안으로 묶어 발표합니다. 사전기획의 마지막 목표는 완벽한 기획서가 아니라, 다음 단계로 넘길 수 있는 방향 문서를 만드는 것입니다.

## 1. 핵심 개념: "등장인물과 무대를 정리해 공연을 준비하기"

연극을 준비할 때는 배우와 무대가 필요합니다. 배우가 어떤 성격인지, 무대가 어떤 장소인지 정해져야 대사, 의상, 조명, 동선이 맞춰집니다.

게임에서도 캐릭터와 배경은 단순한 꾸미기가 아닙니다. 플레이어가 누구를 조작하거나 만나게 되는지, 어떤 장소에서 행동하는지 정리해야 시스템과 아트 방향이 이어집니다.

### 이 단어는 무슨 뜻인가요?

- **캐릭터 기획**: 캐릭터의 역할, 성격, 외형, 기능을 정리하는 일입니다.
- **주요 캐릭터**: 플레이어, 동료, 적, 상인, 안내자처럼 게임 흐름에 영향을 주는 캐릭터입니다.
- **배경 기획**: 게임이 진행되는 장소와 분위기를 정리하는 일입니다.
- **피치**: 아이디어를 짧고 설득력 있게 발표하는 일입니다.
- **기획 초안**: 이후 상세 기획으로 발전시키기 위한 첫 문서 묶음입니다.

## 2. 캐릭터와 배경은 게임 기능과 연결되어야 한다

캐릭터 설정은 "멋있다"에서 끝나면 부족합니다. 게임에서 어떤 역할을 하는지 함께 적어야 합니다.

| 설정 항목 | 기능과 연결하는 질문 |
| :--- | :--- |
| 플레이어 캐릭터 | 플레이어는 어떤 능력으로 문제를 해결하는가? |
| 조력자 | 튜토리얼, 상점, 퀘스트 안내를 맡을 수 있는가? |
| 적 캐릭터 | 어떤 실패와 도전을 만드는가? |
| 배경 장소 | 어떤 플레이 행동을 유도하는가? |
| 분위기 | UI, 사운드, 색감에 어떤 방향을 주는가? |

기획자는 모든 그림을 직접 그리지 않아도 됩니다. 대신 다른 팀원이 이해할 수 있게 역할과 방향을 정리해야 합니다.

## 문서 실습 2: 최종 발표용 기획 초안 묶기

**미션:** DAY 01~06 산출물을 5분 발표용 순서로 정리합니다.

```text
# 최종 기획 발표 순서

1. 게임 가제와 로그라인
-

2. 타겟 사용자
-

3. 시장과 유사 게임 분석에서 발견한 점
-

4. 핵심 재미와 플레이 루프
-

5. 세계관과 플레이어 목표
-

6. 주요 캐릭터와 배경
-

7. 수익 모델
-

8. 개발 시 가장 큰 위험과 해결 방향
-

9. 한 문장 마무리
-
```

### 발표 체크리스트

- 게임을 한 문장으로 설명할 수 있는가?
- 타겟 사용자가 너무 넓지 않은가?
- 유사 게임 분석에서 가져온 근거가 있는가?
- 핵심 재미와 플레이 루프가 연결되는가?
- 세계관, 캐릭터, 배경이 플레이와 연결되는가?
- 수익 모델이 사용자 경험을 해치지 않도록 설명했는가?
- 가장 큰 위험을 숨기지 않고 해결 방향을 제시했는가?

### 생각해보기

1. 좋은 캐릭터 설정은 외형 설명만으로 충분할까요?
2. 발표에서 모든 설정을 다 말하려고 하면 어떤 문제가 생길까요?
3. 기획 초안을 개발자에게 넘길 때 가장 먼저 보여줘야 할 정보는 무엇일까요?

## 오늘의 정리

- 캐릭터와 배경은 게임의 기능, 플레이, 분위기와 연결되어야 합니다.
- 최종 발표는 길고 자세한 설명보다 핵심 방향을 설득력 있게 전달하는 것이 중요합니다.
- 게임 사전기획 과정의 실습은 코딩이 아니라 분석표, 제안서, 설정서, 발표 자료 같은 문서 산출물 작성입니다.
