# DAY 02: 타겟 사용자와 수익 모델

오늘은 게임을 플레이할 사람과 게임이 유지될 방식을 정리합니다. 좋은 게임 아이디어도 "누구에게 어떤 방식으로 제공할 것인가"가 흐릿하면 실제 프로젝트로 이어지기 어렵습니다.

## 1. 핵심 개념: "손님과 결제 방식을 먼저 정하는 일"

음식점을 생각해봅시다. 학생이 많이 오는 골목인지, 직장인이 많은 곳인지에 따라 메뉴와 가격이 달라집니다. 점심 한 끼를 파는 식당인지, 예약제로 운영하는 코스 요리집인지도 다릅니다.

게임도 마찬가지입니다. 초등학생이 즐기는 캐주얼 게임과 성인이 오래 붙잡는 하드코어 RPG는 플레이 시간, 난이도, 결제 방식이 달라집니다.

### 이 단어는 무슨 뜻인가요?

- **타겟 사용자**: 게임을 가장 먼저 만족시켜야 할 핵심 사용자입니다.
- **페르소나**: 실제 사용자처럼 상상해 만든 대표 사용자 프로필입니다.
- **수익 모델**: 게임이 돈을 버는 방식입니다.
- **패키지 판매**: 게임을 한 번 구매하고 플레이하는 방식입니다.
- **부분 유료화**: 기본 플레이는 무료이고 아이템, 편의 기능, 꾸미기 요소 등을 판매하는 방식입니다.

## 2. 타겟 사용자를 좁혀야 하는 이유

"모두가 좋아하는 게임"은 듣기에는 좋지만 실제 기획에서는 위험합니다. 모두를 만족시키려 하면 난이도, 그래픽, 조작, 수익 모델이 한 방향으로 모이지 않습니다.

타겟 사용자는 다음처럼 좁혀 잡습니다.

| 넓은 표현 | 더 나은 표현 |
| :--- | :--- |
| 게임 좋아하는 사람 | 하루 10분씩 모바일 게임을 켜는 직장인 |
| RPG 유저 | 캐릭터 수집과 자동 전투를 좋아하는 모바일 RPG 유저 |
| 액션 게임 유저 | 패드 조작과 보스전을 좋아하는 콘솔 액션 유저 |

좁게 잡는다고 다른 사용자를 버리는 것은 아닙니다. 먼저 만족시킬 중심 사용자를 정하는 것입니다.

## 3. 수익 모델은 재미 구조와 맞아야 한다

수익 모델은 단순히 돈을 붙이는 단계가 아닙니다. 게임의 재미 구조와 맞아야 합니다.

| 게임 구조 | 어울리는 수익 모델 예시 | 주의할 점 |
| :--- | :--- | :--- |
| 짧게 반복 플레이 | 광고, 배틀패스, 꾸미기 상품 | 광고가 플레이 흐름을 끊지 않게 하기 |
| 긴 스토리 중심 | 패키지 판매, DLC | 초반 체험에서 매력을 보여주기 |
| 캐릭터 수집 | 부분 유료화, 시즌 상품 | 과금 압박이 지나치지 않게 하기 |
| 경쟁 중심 | 시즌 패스, 스킨 판매 | 돈이 실력 차이를 만들지 않게 하기 |

## 문서 실습: 사용자 페르소나와 수익 모델 정리

**미션:** DAY 01에서 고른 게임 장르를 기준으로 대표 사용자 1명과 수익 모델을 정합니다.

```text
게임 가제:

1. 대표 사용자 페르소나
- 이름:
- 나이:
- 주로 쓰는 플랫폼:
- 하루 플레이 가능 시간:
- 좋아하는 게임:
- 게임에서 기대하는 것:
- 싫어하는 것:

2. 사용자 목표
- 이 사용자는 우리 게임에서 무엇을 얻고 싶은가?

3. 수익 모델
- 선택한 수익 모델:
- 이 모델을 선택한 이유:
- 사용자가 부담스럽게 느낄 수 있는 지점:
- 부담을 줄이는 방법:

4. 한 문장 정리
- 우리 게임은 누구에게 어떤 가치를 주고, 어떤 방식으로 유지되는가?
```

### 작성 예시

```text
게임 가제: 10분 던전 상점

1. 대표 사용자 페르소나
- 이름: 민수
- 나이: 24세
- 주로 쓰는 플랫폼: 모바일
- 하루 플레이 가능 시간: 출퇴근 중 10~20분
- 좋아하는 게임: 방치형 RPG, 로그라이트
- 게임에서 기대하는 것: 짧은 시간에도 성장했다는 느낌
- 싫어하는 것: 긴 튜토리얼, 강제 광고

2. 사용자 목표
- 짧은 접속으로 캐릭터와 상점이 조금씩 성장하는 만족감을 얻고 싶다.

3. 수익 모델
- 선택한 수익 모델: 무료 플레이 + 꾸미기 아이템 + 선택형 광고 보상
- 이 모델을 선택한 이유: 짧은 플레이와 반복 접속 구조에 어울림
- 사용자가 부담스럽게 느낄 수 있는 지점: 광고를 보지 않으면 손해 보는 느낌
- 부담을 줄이는 방법: 광고 보상은 선택형으로 두고 핵심 진행은 막지 않는다.

4. 한 문장 정리
- 10분 던전 상점은 바쁜 모바일 유저에게 짧은 성장 만족을 주고, 선택형 광고와 꾸미기 상품으로 유지된다.
```

### 생각해보기

1. 부분 유료화 게임에서 사용자가 불공정하다고 느끼는 순간은 언제일까요?
2. 타겟 사용자를 좁히면 기획이 쉬워지는 이유는 무엇일까요?
3. 수익 모델이 게임의 재미를 해치지 않으려면 무엇을 조심해야 할까요?

## 오늘의 정리

- 타겟 사용자는 기획의 기준점입니다.
- 페르소나는 막연한 사용자를 실제 사람처럼 생각하게 해 주는 도구입니다.
- 수익 모델은 게임의 플레이 구조, 사용자 기대, 서비스 방식과 함께 설계해야 합니다.
