# DAY 03: 장르와 게임 콘텐츠 분석

오늘은 게임의 장르와 핵심 재미를 분석합니다. 장르는 단순한 이름표가 아니라 사용자가 어떤 재미를 기대해도 되는지 알려주는 약속입니다.

## 1. 핵심 개념: "메뉴 이름을 보면 맛을 예상한다"

메뉴판에 "김치찌개"라고 적혀 있으면 사람들은 어느 정도의 맛을 예상합니다. 그런데 김치찌개를 주문했는데 차가운 디저트가 나오면 당황합니다.

게임 장르도 비슷합니다. "RPG"라고 하면 성장, 장비, 전투, 역할 수행을 기대합니다. "퍼즐"이라고 하면 규칙을 이해하고 머리를 써서 해결하는 재미를 기대합니다. 장르를 정한다는 것은 사용자의 기대를 정리하는 일입니다.

### 이 단어는 무슨 뜻인가요?

- **장르**: 게임의 플레이 방식과 재미를 묶어 부르는 분류입니다.
- **핵심 재미**: 이 게임을 계속 하게 만드는 가장 중요한 즐거움입니다.
- **게임 루프**: 플레이어가 반복해서 수행하는 행동 흐름입니다.
- **차별점**: 비슷한 게임 사이에서 우리 게임을 다르게 보이게 하는 요소입니다.
- **콘텐츠**: 플레이어가 경험하는 스테이지, 캐릭터, 규칙, 보상, 이야기 등의 내용입니다.

## 2. 장르 분석에서 볼 것

장르 분석은 "이 게임은 액션이다"라고 끝내는 일이 아닙니다. 다음 요소를 함께 봐야 합니다.

| 분석 항목 | 질문 |
| :--- | :--- |
| 플레이 방식 | 플레이어는 주로 무엇을 하는가? |
| 반복 구조 | 매번 어떤 행동을 반복하는가? |
| 보상 | 플레이어는 무엇을 얻는가? |
| 실패 | 어떤 상황에서 실패하는가? |
| 성장 | 시간이 지나며 무엇이 달라지는가? |
| 차별점 | 비슷한 게임과 무엇이 다른가? |

장르의 핵심 재미를 찾으면 이후 시스템 기획, 레벨 기획, UI 기획으로 넘어갈 때 기준이 생깁니다.

## 문서 실습: 유사 게임 콘텐츠 분석표

**미션:** 유사 게임 2개를 골라 핵심 재미와 반복 구조를 비교합니다.

```text
분석할 장르:

유사 게임 A:
유사 게임 B:

1. 플레이어가 반복하는 행동
- 게임 A:
- 게임 B:

2. 가장 큰 재미
- 게임 A:
- 게임 B:

3. 보상 구조
- 게임 A:
- 게임 B:

4. 불편하거나 아쉬운 점
- 게임 A:
- 게임 B:

5. 우리 게임에 가져올 점
-

6. 우리 게임에서 피할 점
-

7. 우리 게임의 핵심 재미 한 문장
-
```

### 작성 예시

```text
분석할 장르: 로그라이트 액션

유사 게임 A: Hades
유사 게임 B: Vampire Survivors

1. 플레이어가 반복하는 행동
- 게임 A: 방을 이동하며 적을 처치하고 보상을 선택한다.
- 게임 B: 몰려오는 적을 피하며 자동 공격과 성장 선택을 반복한다.

2. 가장 큰 재미
- 게임 A: 전투 실력과 보상 선택이 함께 쌓이는 재미
- 게임 B: 짧은 시간에 화면이 점점 강해지는 재미

3. 보상 구조
- 게임 A: 방 클리어 보상, 무기 강화, 이야기 진행
- 게임 B: 레벨업 선택, 캐릭터 해금, 조합 발견

4. 불편하거나 아쉬운 점
- 게임 A: 한 판이 길게 느껴질 수 있다.
- 게임 B: 후반 화면 정보가 복잡해질 수 있다.

5. 우리 게임에 가져올 점
- 매번 다른 보상 선택으로 반복 플레이를 덜 지루하게 만든다.

6. 우리 게임에서 피할 점
- 처음부터 정보와 이펙트를 너무 많이 보여주지 않는다.

7. 우리 게임의 핵심 재미 한 문장
- 짧은 던전에서 매번 다른 선택으로 캐릭터를 빠르게 성장시키는 재미
```

### 생각해보기

1. 장르를 섞으면 항상 새롭고 좋은 게임이 될까요?
2. "핵심 재미"와 "많은 기능"은 같은 말일까요?
3. 유사 게임 분석에서 가져올 점과 피할 점을 나누는 이유는 무엇일까요?

## 오늘의 정리

- 장르는 사용자의 기대를 정하는 이름표입니다.
- 콘텐츠 분석은 게임 안에서 플레이어가 무엇을 반복하고 왜 계속하는지 보는 과정입니다.
- 좋은 사전기획은 기능 목록보다 핵심 재미를 먼저 선명하게 만듭니다.
