# 게임 사전기획 포트폴리오 과제

## 과제 개요

하나의 게임 아이디어를 정하고, 시장 분석부터 최종 발표까지 이어지는 사전기획 문서 묶음을 작성합니다. 이 과제는 코딩 결과물이 아니라 개발 전 방향을 정리한 문서 산출물을 평가합니다.

## 제출 산출물

1. 시장과 트렌드 분석표
2. 타겟 사용자 페르소나
3. 수익 모델 정리표
4. 유사 게임 콘텐츠 분석표
5. 1페이지 게임 아이디어 제안서
6. 세계관과 시나리오 초안
7. 캐릭터와 배경 설정서
8. 5분 발표용 요약 자료

## 평가 기준

| 평가 항목 | 확인 내용 |
| :--- | :--- |
| 시장 분석 | 유사 게임과 사용자 분석이 기획 방향과 연결되는가 |
| 타겟 설정 | 핵심 사용자가 구체적으로 정의되었는가 |
| 아이디어 제안 | 장르, 플랫폼, 핵심 재미, 플레이 루프가 분명한가 |
| 콘셉트 정리 | 세계관, 시나리오, 캐릭터, 배경이 서로 어울리는가 |
| 현실성 | 개발 위험과 해결 방향을 간단히 제시했는가 |
| 발표 전달력 | 5분 안에 게임의 방향을 이해시킬 수 있는가 |

## 제출 형식

- Markdown, PDF, PPT 중 하나로 제출합니다.
- 모든 표와 문장은 직접 작성합니다.
- 이미지 자료를 사용할 경우 출처를 함께 적습니다.
- 게임 제목은 가제여도 괜찮습니다.

## 발표 구성

```text
1. 게임 가제와 로그라인
2. 타겟 사용자
3. 시장과 유사 게임 분석
4. 핵심 재미와 플레이 루프
5. 세계관, 캐릭터, 배경
6. 수익 모델
7. 개발 위험과 해결 방향
8. 마무리 한 문장
```

## 주의사항

- 설정을 많이 쓰는 것보다 게임 방향이 선명한 것이 더 중요합니다.
- 유사 게임을 조사할 때 단순 감상문으로 끝내지 말고, 우리 게임에 가져올 점과 피할 점을 나누어 정리합니다.
- 수익 모델은 사용자 경험을 해치지 않는 방식으로 설명합니다.
- 발표에서는 모든 설정을 읽지 말고 핵심 판단 근거만 말합니다.
