# DAY 05: 세계관과 시나리오 초안

오늘은 게임의 배경 세계와 이야기 흐름을 정리합니다. 사전기획에서의 세계관과 시나리오는 소설을 완성하는 일이 아니라, 플레이어가 왜 이 게임 속 행동을 하는지 납득하게 만드는 기준을 세우는 일입니다.

## 1. 핵심 개념: "놀이공원의 테마를 정하는 일"

놀이공원에 들어가면 구역마다 분위기가 있습니다. 서부 마을, 우주 기지, 마법 학교처럼 테마가 정해져 있으면 놀이기구, 음악, 안내판, 직원 복장까지 같은 방향으로 맞출 수 있습니다.

게임 세계관도 이런 역할을 합니다. 세계관이 정리되면 캐릭터, 배경, UI, 사운드, 퀘스트의 방향이 흔들리지 않습니다.

### 이 단어는 무슨 뜻인가요?

- **세계관**: 게임 세계가 어떤 규칙과 분위기로 움직이는지 정리한 설정입니다.
- **시간적 배경**: 이야기가 언제 일어나는지에 대한 설정입니다.
- **공간적 배경**: 이야기가 어디에서 일어나는지에 대한 설정입니다.
- **시나리오**: 플레이어가 경험할 사건과 흐름을 정리한 이야기 구조입니다.
- **플레이 동기**: 플레이어가 게임 속 행동을 해야 하는 이유입니다.

## 2. 세계관은 설정 자랑이 아니라 선택 기준이다

세계관을 만들 때 너무 많은 고유명사와 역사를 먼저 쓰면 수업에서는 오히려 어려워집니다. 먼저 아래 질문에 답합니다.

| 질문 | 예시 |
| :--- | :--- |
| 이 세계는 어떤 분위기인가? | 밝은 모험, 어두운 생존, 귀여운 판타지 |
| 플레이어는 어떤 역할인가? | 용사, 상점 주인, 조사관, 관리자 |
| 주요 문제는 무엇인가? | 던전 폭주, 도시 오염, 기억 상실 |
| 플레이어는 왜 행동하는가? | 생존, 성장, 구출, 탐험, 복구 |
| 게임의 반복 행동과 어떻게 연결되는가? | 전투, 제작, 탐색, 거래, 퍼즐 |

세계관은 "멋진 설정"보다 "게임 플레이를 설명해 주는 설정"이어야 합니다.

## 문서 실습: 세계관과 시나리오 1장 초안

**미션:** DAY 04의 게임 아이디어에 어울리는 세계관과 시나리오 흐름을 작성합니다.

```text
# 세계관과 시나리오 초안

1. 세계의 한 문장 설명
-

2. 시간적 배경
-

3. 공간적 배경
-

4. 플레이어의 역할
-

5. 세계의 주요 문제
-

6. 플레이어의 목표
-

-

8. 중간 진행
-

9. 마지막 목표
-

10. 게임 플레이와 연결되는 설정
- 반복 행동:
- 보상:
- 성장:
- 실패 이유:
```

### 작성 예시

```text
# 세계관과 시나리오 초안

1. 세계의 한 문장 설명
- 던전이 일상화된 왕국에서 용사와 상인이 함께 살아가는 코믹 판타지 세계

2. 시간적 배경
- 마왕이 사라진 뒤, 던전 탐험이 하나의 직업이 된 시대

3. 공간적 배경
- 왕국 외곽의 초보자 던전 입구와 작은 상점 마을

4. 플레이어의 역할
- 던전 앞 상점을 물려받은 초보 상점 주인

5. 세계의 주요 문제
- 던전 난이도가 갑자기 올라가 초보 용사들이 계속 실패한다.

6. 플레이어의 목표
- 용사들에게 알맞은 장비를 판매하고 상점을 성장시켜 던전 문제를 해결한다.

7. 시작 상황
- 낡은 상점과 기본 포션 몇 개만 가진 상태에서 첫 손님을 맞이한다.

8. 중간 진행
- 새로운 재료와 제작법을 얻고, 더 강한 용사와 몬스터 정보를 파악한다.

9. 마지막 목표
- 던전 폭주의 원인을 찾아 왕국 최고의 지원 상점이 된다.

10. 게임 플레이와 연결되는 설정
- 반복 행동: 손님 파악 -> 아이템 추천 -> 판매 -> 재료 획득
- 보상: 골드, 재료, 손님 평판
- 성장: 상점 확장, 제작대 강화, 상품 해금
- 실패 이유: 손님에게 맞지 않는 장비를 팔아 던전 공략에 실패함
```

### 생각해보기

1. 세계관 설정이 많아도 게임 플레이와 연결되지 않으면 어떤 문제가 생길까요?
2. 플레이어의 역할이 분명하면 기획이 쉬워지는 이유는 무엇일까요?
3. 시나리오가 없어도 되는 게임과 필요한 게임은 어떻게 다를까요?

## 오늘의 정리

- 세계관은 게임의 분위기와 선택 기준을 잡아 주는 설정입니다.
- 시나리오는 플레이어가 왜 행동하는지 설명해 주는 흐름입니다.
- 사전기획 단계에서는 긴 이야기보다 플레이와 연결되는 한 장짜리 초안이 더 중요합니다.
