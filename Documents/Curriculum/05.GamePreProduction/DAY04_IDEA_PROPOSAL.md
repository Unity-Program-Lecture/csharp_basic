# DAY 04: 게임 아이디어 제안서 작성

오늘은 지금까지 분석한 내용을 바탕으로 게임 아이디어 제안서를 작성합니다. 아이디어 제안서는 긴 기획서가 아니라, "이 게임을 한번 만들어볼 만하다"는 판단을 돕는 짧은 설득 문서입니다.

## 1. 핵심 개념: "친구에게 게임을 한 번에 설명하기"

좋은 아이디어는 길게 설명하기 전에 짧게 잡힙니다. 친구에게 "이 게임은 어떤 게임이야?"라는 질문을 받았을 때 한두 문장으로 말할 수 있어야 합니다.

예를 들어 "고양이가 운영하는 던전 편의점에서 용사에게 아이템을 팔며 성장하는 방치형 경영 RPG"라고 말하면 장르, 소재, 플레이 방향이 어느 정도 보입니다.

### 이 단어는 무슨 뜻인가요?

- **게임 가제**: 아직 확정되지 않은 임시 게임 이름입니다.
- **로그라인**: 게임의 핵심을 한 문장으로 설명한 문장입니다.
- **기획 의도**: 왜 이 게임을 만들고 싶은지 설명하는 문장입니다.
- **핵심 플레이**: 플레이어가 가장 자주 하게 될 행동입니다.
- **제안서**: 다른 사람이 아이디어를 검토할 수 있도록 정리한 짧은 문서입니다.

## 2. 아이디어 제안서에 들어갈 내용

초기 제안서는 너무 자세할 필요가 없습니다. 대신 다음 항목은 빠지지 않는 것이 좋습니다.

| 항목 | 설명 |
| :--- | :--- |
| 게임 가제 | 기억하기 쉬운 임시 제목 |
| 장르와 플랫폼 | 어떤 장르이며 어디서 플레이하는지 |
| 타겟 사용자 | 가장 먼저 만족시킬 사용자 |
| 로그라인 | 게임을 한 문장으로 소개 |
| 핵심 재미 | 사용자가 계속 플레이할 이유 |
| 핵심 플레이 | 사용자가 반복할 행동 |
| 차별점 | 유사 게임과 다른 점 |
| 수익 모델 | 서비스 또는 판매 방식 |

## 문서 실습: 1페이지 게임 아이디어 제안서

**미션:** DAY 01~03에서 작성한 분석 내용을 바탕으로 1페이지 제안서를 완성합니다.

```text

1. 게임 가제
-

2. 장르 / 플랫폼
-

3. 타겟 사용자
-

4. 로그라인
-

5. 기획 의도
-

6. 핵심 재미 3가지
- 재미 1:

- 재미 3:

7. 핵심 플레이 루프
시작 -> 행동 -> 보상 -> 성장 -> 다시 도전

- 시작:
- 행동:
- 보상:
- 성장:
- 다시 도전하게 만드는 이유:

-

9. 수익 모델
-

10. 개발 시 가장 큰 위험
-
```

### 작성 예시

```text
# 게임 아이디어 제안서

1. 게임 가제
- 10분 던전 상점

2. 장르 / 플랫폼
- 모바일 방치형 경영 RPG

3. 타겟 사용자
- 짧은 시간에 성장과 수집을 즐기고 싶은 모바일 RPG 유저

4. 로그라인
- 던전 입구의 작은 상점을 운영하며 용사에게 장비를 팔고 몬스터 재료로 가게를 성장시키는 게임

5. 기획 의도
- 전투 중심 RPG에서 벗어나, 전투를 준비시키는 상점 주인의 관점으로 성장 재미를 제공한다.

6. 핵심 재미 3가지
- 재미 1: 손님에게 맞는 아이템을 추천하는 선택 재미
- 재미 2: 재료와 골드로 상점이 커지는 성장 재미
- 재미 3: 짧은 접속에도 보상이 쌓이는 방치 재미

7. 핵심 플레이 루프
- 시작: 용사가 상점에 방문한다.
- 행동: 필요한 장비를 추천하고 판매한다.
- 보상: 골드와 몬스터 재료를 얻는다.
- 성장: 상점, 장비 제작대, 진열대를 강화한다.
- 다시 도전하게 만드는 이유: 더 강한 용사가 찾아오고 새로운 던전 재료가 열린다.

8. 차별점
- 플레이어가 용사가 아니라 용사를 준비시키는 상점 주인이다.

9. 수익 모델
- 무료 플레이 + 꾸미기 상품 + 선택형 광고 보상

10. 개발 시 가장 큰 위험
- 방치 보상만으로는 플레이가 단조로울 수 있다.
```

### 생각해보기

1. 로그라인이 길어지면 어떤 문제가 생길까요?
2. 핵심 재미 3가지를 넘어서 너무 많이 적으면 왜 흐려질까요?
3. 개발 위험을 제안서에 적는 것은 약점일까요, 준비된 태도일까요?

## 오늘의 정리

- 아이디어 제안서는 긴 설정집이 아니라 검토 가능한 짧은 설득 문서입니다.
- 좋은 제안서는 타겟, 장르, 핵심 재미, 반복 구조가 한 방향을 바라봅니다.
- 사전기획의 핵심 산출물은 "생각"이 아니라 다른 사람이 읽고 판단할 수 있는 "문서"입니다.
