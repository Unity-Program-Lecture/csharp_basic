# 🚀 Day 06: 배열과 매개변수 한정자 (복사본 vs 원본)

오늘의 목표는 **"데이터를 연속적으로 담는 배열을 배우고, 함수에 데이터를 줄 때 복사본을 줄지 원본을 줄지 결정하는 법을 배운다"**입니다.

---

## 1. 배열(Array): "연속된 데이터 상자"
배열은 동일한 타입의 데이터를 메모리에 다닥다닥 붙여서 저장하는 가장 기본적인 자료구조입니다.
- **특징**: 0번부터 시작합니다. 한 번 크기를 정하면 바꿀 수 없습니다.
- **이름표**: `int[] scores = new int[5];` (5칸짜리 정수 배열)

---

## 2. 매개변수 한정자: "시험지 비유"

### 🍎 기본값 (복사본 전달)
- **비유**: 친구에게 내 시험지 **복사본**을 주는 것. 친구가 낙서해도 내 원본은 깨끗합니다.

### 📝 ref (참조 전달 - 원본 직접 주기)
- **비유**: 내 **원본 시험지**를 직접 주는 것. 친구가 낙서하면 내 시험지도 낙서가 됩니다.
- **조건**: 넣기 전에 반드시 값이 들어있어야 합니다.

### 📥 out (출력 전용 - 빈 종이 주기)
- **비유**: 친구에게 **빈 종이**를 주며 "답 좀 적어서 돌려줘" 하는 것.
- **조건**: 함수가 끝나기 전에 반드시 값을 채워야 합니다.

---

## 💻 실습 예제: 두 변수의 값 바꾸기 (Swap)
**미션:** `ref` 키워드를 사용하여 함수 밖의 두 변수 값을 서로 바꾸는 기능을 구현해 보세요.

<details>
<summary>코드 보기</summary>

```csharp
using System;

class Program
{
    static void Swap(ref int a, ref int b)
    {
        int temp = a;
        a = b;
        b = temp;
    }

    static void Main()
    {
        int x = 10, y = 20;
        Console.WriteLine($"바뀌기 전: x={x}, y={y}");
        
        Swap(ref x, ref y); // 원본을 보냅니다.
        
        Console.WriteLine($"바뀐 후: x={x}, y={y}"); // 결과: x=20, y=10
    }
}
```

</details>
