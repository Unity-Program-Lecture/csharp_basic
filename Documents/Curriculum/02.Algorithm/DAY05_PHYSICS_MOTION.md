# 🚀 Day 05: 게임 물리 - 운동의 기초 (Speed & Acceleration)

오늘의 목표는 "**위치, 속도, 가속도의 관계를 이해하고, 프레임마다 변화량을 누적하여 등가속도 운동을 구현한다**"입니다.

---

## 1. 위치, 속도, 가속도의 관계
게임 엔진은 매 프레임 아주 짧은 시간(`DeltaTime`) 동안의 변화를 계산하여 물체를 이동시킵니다.

- **속력** (Speed): 단순히 물체가 얼마나 빠르게 움직이는지를 나타내는 "**스칼라 (Scalar)**" 값입니다.
- **속도** (Velocity): 속력에 "**방향**"이 더해진 "**벡터 (Vector)**" 값입니다. 게임 코드에서는 주로 `Vector3`로 표현합니다.
- **가속도** (Acceleration): 속도가 매초 얼마나 바뀌는지를 나타냅니다.
- **누적**: 가속도를 조금씩 더하면 속도가 바뀌고, 속도를 조금씩 더하면 위치가 바뀝니다.

예를 들어 중력은 아래 방향으로 계속 밀어 주는 규칙입니다. 그래서 물체는 처음부터 갑자기 빠르게 떨어지는 것이 아니라, 매 프레임 아래쪽 속도가 조금씩 커지면서 점점 빠르게 내려갑니다.

---

## 2. 등속 직선 운동 (Constant Velocity)
가장 단순한 형태의 운동으로, **가속도가 0**이어서 시간에 따라 속도의 크기와 방향이 변하지 않는 운동입니다.

### 📍 핵심 공식
- **변위 (위치 변화) 공식**

```text
이동 거리 = 속도 x 시간
s = v x t
```

### 🎮 게임 실무에서의 활용
- 캐릭터가 방향키 입력 방향으로 **일정한 속도**로 걷거나 뛰는 기본 이동 로직.
- 일정한 속도로 전방을 향해 날아가는 일반 총알, 화살 등 가속이 필요 없는 투사체.
- **실전 C# 코드**:
  ```csharp
  // 매 프레임 등속도로 이동 (가속도가 없으므로 속도가 고정됨)
  transform.position += direction * speed * Time.deltaTime;
  ```

---

## 3. 등가속도 직선 운동 (Constant Acceleration)
가장 대표적인 실생활 예시는 **중력**입니다. 가속도가 일정하여 시간에 따라 속도가 일정하게 증가하거나 감소하는 운동입니다.

### 📍 핵심 공식
1. **속도 공식**

```text
나중 속도 = 처음 속도 + 가속도 x 시간
v = v0 + a x t
```

2. **변위 (위치 변화) 공식**

```text
이동 거리 = 처음 속도 x 시간 + 1/2 x 가속도 x 시간 x 시간
s = v0 x t + 1/2 x a x t x t
```

이 공식은 외우기 전에 **평균 속도**로 이해하면 쉽습니다.

- 등가속도 운동에서는 속도가 일정한 비율로 늘어나거나 줄어듭니다.
- 그래서 일정 시간 동안의 이동 거리는 "**처음 속도와 마지막 속도의 중간 속도**"로 계속 움직였다고 생각해도 같습니다.
- 즉, `이동 거리 = 평균 속도 x 시간`입니다.

```text
평균 속도 = (처음 속도 + 마지막 속도) / 2
이동 거리 = 평균 속도 x 시간
```

예를 들어 처음 속도가 `0 m/s`이고 3초 뒤 속도가 `30 m/s`라면, 그동안의 평균 속도는 `15 m/s`입니다.

```text
이동 거리 = 15 x 3 = 45m
```

## 💻 실습 예제: 중력 직접 구현하기 (Rigidbody 없이)
유니티의 `Update` 문에서 매 프레임 속도와 위치를 조금씩 바꾸며 중력을 관찰해 봅니다.

> 이 예제는 `Rigidbody`를 대신하는 실전 물리 시스템이 아니라, 가속도와 속도 관계를 눈으로 확인하는 짧은 실험입니다. 실제 충돌, 트리거, 튕김, 물리 상호작용은 다음 수업부터 `Rigidbody`와 `Collider`로 처리합니다.

<details>
<summary>코드 보기</summary>

```csharp
using UnityEngine;

public class ManualGravity : MonoBehaviour
{
    public float gravity = -9.81f;

    [SerializeField]
    // 초기 속도를 에디터에서 지정할 수 있도록 직렬화합니다. (예: 점프는 양수값 입력)
    // 방향(+/-) 정보를 포함하므로 '속도(Velocity)' 변수명을 사용합니다.
    private float currentVelocityY = 0f;

    void Update()
    {
        // 1. 중력 때문에 아래쪽 속도가 조금씩 커집니다. (v = v0 + at)
        // 가속도의 방향에 따라 속도가 어느 방향으로 바뀔지 결정됩니다.
        currentVelocityY += gravity * Time.deltaTime;

        // 2. 지금 속도만큼 위치를 조금 이동합니다.
        // Time.deltaTime을 곱하면 프레임 속도와 상관없이 비슷한 움직임이 됩니다.
        Vector3 pos = transform.position;
        pos.y += currentVelocityY * Time.deltaTime;

        // 3. 지면 충돌 시 정지 (임시 로직)
        if (pos.y < 0)
        {
            pos.y = 0;
            currentVelocityY = 0; // 속도를 0으로 만들어 정지시킴
        }

        transform.position = pos;
    }
}
```

</details>
