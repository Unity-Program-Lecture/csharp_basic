# 게임 알고리즘 포트폴리오 과제

- 과정: 게임 알고리즘
- NCS 능력단위: 0803020526_18v4 게임 알고리즘
- 평가 환경: Unity 6, C#, Input System, UGUI
- 권장 범위: 학습 시간 안에 완성 가능한 단일 Unity 6 미니 프로젝트

## 과제명

Unity 6 기반 몬스터 사냥 알고리즘 미니 시뮬레이터

## 과제 목표

게임 수학, 물리, 자료구조, 탐색 알고리즘을 하나의 작은 Unity 6 씬으로 통합해 NCS 게임 알고리즘 수행준거를 관찰 가능한 포트폴리오로 제출합니다.

## 필수 구현

1. 플레이어 이동
   - Input System으로 키보드 이동을 처리합니다.
   - 이동 방향은 `Vector3`와 정규화를 사용합니다.

2. 몬스터 감지와 회전
   - 내적으로 시야각 안의 플레이어를 판별합니다.
   - `Quaternion.LookRotation` 또는 `Quaternion.Slerp`로 부드럽게 회전합니다.

3. 충돌 또는 거리 판정
   - `sqrMagnitude`를 사용해 거리 기반 공격/회피 판정을 구현합니다.
   - Rigidbody 또는 Collider를 사용하는 경우 Unity 6 물리 이벤트 흐름을 설명합니다.

4. 자료구조 활용
   - `List` 또는 `Dictionary`로 몬스터, 아이템, 노드 중 하나를 관리합니다.
   - 선택한 자료구조의 이유를 README 또는 주석으로 설명합니다.

5. 길찾기 또는 상태 전이
   - 그래프/BFS/DFS/A* 중 하나를 선택해 이동 경로 또는 탐색 로직을 구현합니다.
   - 구현 범위가 작더라도 노드, 간선, 비용 또는 상태 전이 흐름이 확인되어야 합니다.

6. UGUI 디버그 표시
   - 현재 상태, 탐색 결과, 거리, 감지 여부 중 2개 이상을 UGUI 텍스트로 표시합니다.
