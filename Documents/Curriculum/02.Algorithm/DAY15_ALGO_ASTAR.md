# 🚀 Day 15: 고급 길찾기 알고리즘 (A* Algorithm)

오늘의 목표는 **"가장 널리 쓰이는 길찾기 알고리즘인 A*(에이스타) 알고리즘의 원리를 이해하고, 전체 교육과정의 결과물을 포트폴리오로 제출한다"**입니다.

---

## 1. 💡 이론 (30%): A* 알고리즘의 핵심 (F = G + H)
A* 알고리즘은 무작정 길을 찾는 것이 아니라, "목적지 방향"을 고려하여 아주 스마트하게 최단 경로를 찾아냅니다.

- **G (시작점으로부터의 비용)**: 지금까지 이동하면서 쓴 실제 비용입니다.
- **H (휴리스틱, Heuristic)**: 현재 위치에서 목적지까지 남은 "예상 비용"입니다. (장애물을 무시한 직선거리 등)
- **F (총 예상 비용)**: `F = G + H`. A* 알고리즘은 항상 주변 타일 중 **F 값이 가장 작은 노드**를 다음 이동 경로로 선택합니다.

### 📌 오픈 리스트와 클로즈드 리스트
- **Open List**: 앞으로 탐색해볼 가치가 있는 타일(노드)들의 대기열입니다.
- **Closed List**: 이미 탐색을 마쳐서 다시 볼 필요가 없는 타일들의 목록입니다.

## 2. 💻 실습 (70%): A* 알고리즘 로직 분석 및 포트폴리오 정리
**미션:** A* 알고리즘의 길찾기 로직(F, G, H 계산)을 분석하고 기존 프로젝트에 적용한 뒤, 포트폴리오 제출을 위한 작업 내역서를 작성하세요.

<details>
<summary>코드 보기</summary>

```csharp
using UnityEngine;

// A* 알고리즘을 위한 기본 노드(Node) 구조체 예시
public class Node
{
    public int gridX;
    public int gridY;
    public bool isWalkable;

    // 길찾기 비용
    public int gCost; // 시작점부터의 거리
    public int hCost; // 목적지까지의 예상 거리
    
    public Node parentNode; // 경로를 역추적하기 위한 부모 노드

    // F 비용 계산 프로퍼티
    public int fCost 
    {
        get { return gCost + hCost; }
    }

    public Node(bool _isWalkable, int _gridX, int _gridY)
    {
        isWalkable = _isWalkable;
        gridX = _gridX;
        gridY = _gridY;
    }
}

// 실제 A* 탐색 로직은 Open List에서 가장 F Cost가 낮은 노드를 꺼내고,
// 목적지라면 부모 노드(parentNode)를 따라 역추적하여 최종 경로를 완성합니다.
```

## ✍️ 평가 문항 대비 퀴즈
1. **문제:** A* 알고리즘에서 F 비용을 계산하는 공식은 무엇인가요?
   - **정답:** F = G + H (시작점부터의 실제 비용 + 목적지까지의 예상 비용)
2. **문제:** A* 알고리즘이 무작위 탐색(BFS 등)보다 목적지를 빠르게 찾을 수 있는 이유는 어떤 비용(Cost)을 추가로 계산하기 때문인가요?
   - **정답:** 휴리스틱(Heuristic, H) 비용을 계산하여 목적지 방향으로 우선 탐색하기 때문입니다.
