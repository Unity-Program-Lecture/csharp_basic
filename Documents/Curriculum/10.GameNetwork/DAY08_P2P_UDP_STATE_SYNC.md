# DAY 08: P2P와 UDP 상태 동기화

오늘은 Peer끼리 UDP 상태를 교환할 때 최신 상태를 우선하는 이유를 확인합니다.

## 1. 핵심 개념: "여러 사람이 서로에게 현재 위치를 알리기"

- **P2P (Peer-to-Peer)**: 참여자가 서버만 바라보지 않고 서로 통신 상대가 될 수 있는 모델입니다.
- **Peer**: P2P 네트워크에 참여하는 한 프로그램 또는 장치입니다.
- **시퀀스 번호 (Sequence Number)**: 메시지의 새로움을 비교하기 위해 붙이는 증가 번호입니다.
- **동기화 (Synchronization)**: 여러 참여자가 같은 상태를 보도록 맞추는 일입니다.

## 2. 안내형 실습: 최신 위치만 반영하기

**미션:** `POSITION|sequence|x|y` 중 더 큰 sequence만 화면에 반영합니다.

1. DAY05 수신자에 `lastSequence = -1` 변수를 만듭니다.
2. 송신 메시지를 `POSITION|1|3|5` 형식으로 바꿉니다.
3. 수신자는 `Split('|')`로 세 번째·네 번째 값을 포함해 나눕니다.
4. 받은 sequence가 `lastSequence`보다 크면 위치를 출력하고 `lastSequence`를 바꿉니다.
5. 같거나 작은 sequence면 `오래된 위치 무시`를 출력합니다.
6. 송신자가 순서대로 `POSITION|2|4|5`, `POSITION|1|3|5`를 보내게 합니다.

### 실행해보면

두 번째 메시지는 오래된 위치로 판단되어 화면 상태를 되돌리지 않아야 합니다.

## 응용 실습: 손실 기록
