# 게임 네트워크 프로그래밍 운영 계획

이 문서는 `26국기_교수계획서.pdf`의 `0803020534_18v4 게임 네트워크 프로그래밍` 90시간을 Unity 6과 C#으로 재구성한 운영표입니다. 하루 6시간, 15개 DAY 문서로 운영합니다. DAY00은 설치와 연결 확인을 위한 사전 실습이며 90시간 산정에는 포함하지 않습니다.

## 운영 원칙

- 콘솔 프로젝트에서는 서버, TCP(Transmission Control Protocol), UDP(User Datagram Protocol), 패킷, 비동기의 원리를 확인합니다.
- Unity 6에서는 Netcode for GameObjects (NGO)를 사용해 같은 원리를 게임 오브젝트 동기화로 적용합니다.
- Unity 비동기 실습의 표준은 UniTask입니다. 다만 먼저 표준 C# `Task`와 `CancellationToken`의 공통 원리를 배웁니다.
- 모든 DAY에는 안내형 실습과, 설명 없이 조건만 제시하는 `응용 실습`을 둡니다.
- 공식 평가 방식은 `서술형 + 평가자 체크리스트`입니다. 응용 실습은 포트폴리오 평가가 아닙니다.

## 공통 실습 결과 확인 규칙

네트워크 실습은 실행 창 하나만 보고 통과로 판단하지 않습니다. Host와 Client를 함께 실행하고, 각 창의 화면·Hierarchy·Console을 확인합니다. 오류가 발생하면 `증상 → Console 메시지 → Inspector 연결 → 코드 흐름` 순서로 기록합니다.
