# 🚀 [알고리즘 11] 실전 A*: 유니티 길찾기 시스템 구현

학습 목표: A* 알고리즘의 전체 루프(Open List, Closed List)를 구현하고, 유니티 환경에서 최적화된 경로를 시각화하는 실전 기술을 습득합니다.

---

## 💡 개념 설명 (NCS 알고리즘: 경로 탐색 최적화 및 실무 적용)

### 1. Open List와 Closed List
A* 알고리즘이 효율적으로 작동하기 위해 사용하는 두 개의 명단입니다.

- **Open List (열린 목록)**: "가볼 만한 후보지". 현재 주변 탐색 결과 발견했지만 아직 직접 밟아보지 않은 노드들입니다.
- **Closed List (닫힌 목록)**: "이미 확인 완료". 이미 방문했거나 다시는 갈 필요가 없는 노드들입니다.

### 2. 경로 역추적 (Path Reconstruction)
목적지에 도달하면, 목적지 노드부터 시작해서 '부모(Parent)'를 타고 올라가 시작점까지 연결합니다. 이 과정이 완료되어야 캐릭터가 따라갈 수 있는 실제 '길'이 완성됩니다.

---

## 💻 실습 예제

**미션:** A* 알고리즘의 메인 루프를 구현하여 시작점에서 도착점까지의 경로(Node List)를 반환하는 함수를 작성하세요.

```csharp
using UnityEngine;
using System.Collections.Generic;

public class AStarUnity : MonoBehaviour
{
    public List<Vector2Int> FindPath(Vector2Int start, Vector2Int end)
    {
        // 1. 후보군(Open)과 완료군(Closed) 리스트 준비
        List<AStarBase.Node> openList = new List<AStarBase.Node>();
        HashSet<Vector2Int> closedList = new HashSet<Vector2Int>();

        AStarBase.Node startNode = new AStarBase.Node(start);
        openList.Add(startNode);

        while (openList.Count > 0)
        {
            // 2. F 점수가 가장 낮은 노드 찾기
            AStarBase.Node current = openList[0];
            for (int i = 1; i < openList.Count; i++)
            {
                if (openList[i].fScore < current.fScore) current = openList[i];
            }

            // 3. 목적지 도달 확인
            if (current.pos == end)
            {
                return RetracePath(current);
            }

            openList.Remove(current);
            closedList.Add(current.pos);

            // 4. 주변 타일 탐색 (상하좌우)
            foreach (Vector2Int neighborPos in GetNeighbors(current.pos))
            {
                if (closedList.Contains(neighborPos)) continue;

                int newGScore = current.gScore + 1; // 이동 비용 1 가정
                
                // 새로운 경로가 더 좋다면 Open List에 추가
                AStarBase.Node neighbor = new AStarBase.Node(neighborPos);
                neighbor.gScore = newGScore;
                neighbor.hScore = GetManhattanDistance(neighborPos, end);
                neighbor.parent = current;

                // 이미 Open List에 있고 기존 점수가 더 좋으면 패스
                if (!IsBetterInOpen(openList, neighbor))
                {
                    openList.Add(neighbor);
                }
            }
        }
        return null; // 경로 없음
    }

    private List<Vector2Int> RetracePath(AStarBase.Node endNode)
    {
        List<Vector2Int> path = new List<Vector2Int>();
        AStarBase.Node curr = endNode;
        while (curr != null)
        {
            path.Add(curr.pos);
            curr = curr.parent;
        }
        path.Reverse();
        return path;
    }

    // 보조 함수들 (GetNeighbors, GetManhattanDistance 등은 구현되었다고 가정)
}
```
