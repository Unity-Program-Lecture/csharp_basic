# 🚀 [알고리즘 09] 가중치와 최단 경로: 다익스트라(Dijkstra) 알고리즘

학습 목표: 간선마다 '비용(Weight)'이 다른 가중치 그래프의 개념을 이해하고, 다익스트라 알고리즘을 사용하여 RPG 게임에서 험난한 지형(산, 늪)을 피해가는 최단 경로를 구하는 방법을 배웁니다.

---

## 💡 개념 설명 (NCS 알고리즘: 가중치 그래프 탐색)

### 1. 왜 BFS만으로는 부족할까요?
지난 시간에 배운 BFS는 모든 칸의 이동 비용이 '1'일 때만 최단 거리를 보장합니다. 하지만 실제 RPG 게임은 다릅니다.

- **평지**: 이동 비용 1 (걷기 편함)
- **숲/늪**: 이동 비용 3 (느려짐)
- **산**: 이동 비용 10 (매우 힘듦)

단순히 칸수가 적은 길보다, **"비용의 합계가 가장 적은 길"**을 찾아야 진짜 최단 경로가 됩니다.

### 2. 다익스트라(Dijkstra) 알고리즘의 원리
다익스트라는 현재까지 알고 있는 가장 저렴한 경로를 먼저 탐색하는 '탐욕적(Greedy)' 방식입니다.

- **일상 비유**: 여러 갈래 길 중에서 통행료가 가장 싼 길부터 하나씩 확인하며 목적지까지 가는 최적의 경로를 확정 짓는 과정.
- **핵심 자료구조**: **우선순위 큐(Priority Queue)**를 사용하여 현재 비용이 가장 낮은 노드를 빠르게 뽑아냅니다.

---

## 💻 실습 예제

**미션:** 지형별로 이동 비용이 다른 타일 맵에서 시작점에서 모든 지점까지의 최소 비용을 계산하는 다익스트라 알고리즘 스니펫을 구현하세요.

<details>
<summary>코드 보기</summary>

```csharp
using UnityEngine;
using System;
using System.Collections.Generic;

public class DijkstraPathfinder : MonoBehaviour
{
    public struct Node : IComparable<Node>
    {
        public Vector2Int pos;
        public int cost;

        public Node(Vector2Int p, int c) { pos = p; cost = c; }
        // 우선순위 큐에서 비용이 낮은 순으로 정렬하기 위함
        public int CompareTo(Node other) => cost.CompareTo(other.cost);
    }

    // 지형 비용 데이터 (예: 늪지대 등)
    Dictionary<Vector2Int, int> terrainWeights = new Dictionary<Vector2Int, int>();

    public void RunDijkstra(Vector2Int start)
    {
        // 1. 최소 비용을 저장할 맵과 우선순위 큐 준비
        Dictionary<Vector2Int, int> minCosts = new Dictionary<Vector2Int, int>();
        // 가상의 우선순위 큐 (실제 구현 시 SortedSet이나 별도 PriorityQueue 라이브러리 권장)
        List<Node> pq = new List<Node>(); 

        pq.Add(new Node(start, 0));
        minCosts[start] = 0;

        while (pq.Count > 0)
        {
            // 2. 비용이 가장 낮은 노드 추출
            pq.Sort(); 
            Node current = pq[0];
            pq.RemoveAt(0);

            // 3. 인접 타일 탐색
            Vector2Int[] neighbors = {
                current.pos + Vector2Int.up, current.pos + Vector2Int.down,
                current.pos + Vector2Int.left, current.pos + Vector2Int.right
            };

            foreach (var next in neighbors)
            {
                // 지형 비용 가져오기 (기본 1, 특정 구역은 가중치 부여)
                int stepCost = terrainWeights.ContainsKey(next) ? terrainWeights[next] : 1;
                int newCost = minCosts[current.pos] + stepCost;

                // 4. 더 저렴한 경로를 찾았다면 갱신
                if (!minCosts.ContainsKey(next) || newCost < minCosts[next])
                {
                    minCosts[next] = newCost;
                    pq.Add(new Node(next, newCost));
                    Debug.Log($"{next} 타일 최단 비용 갱신: {newCost}");
                }
            }
        }
    }
}
```
