# 🚀 [알고리즘 07] 계급과 갈래: 트리(Tree) 구조와 스킬 시스템

학습 목표: 부모-자식 관계를 가지는 '트리' 구조를 이해하고, RPG 게임의 스킬 트리(Skill Tree)나 유니티의 계층 구조(Hierarchy) 원리를 배웁니다.

---

## 💡 개념 설명 (NCS 알고리즘: 비선형 자료구조 - 트리)

### 1. 트리(Tree) 구조란 무엇인가요?
트리는 이름처럼 나무가 거꾸로 서 있는 모양입니다. 뿌리(Root)에서 시작해 여러 가지(Branch)가 뻗어 나오고, 마지막에는 잎(Leaf)이 달리는 구조입니다.

- **일상 비유**: 조직도(사장-부장-팀원), 폴더 구조(C드라이브 - Program Files - 게임 폴더).
- **게임에서의 활용**:
  - **스킬 트리**: 이전 스킬을 배워야 다음 스킬을 배울 수 있는 조건부 진행.
  - **유니티 계층 구조**: 게임 속 `Parent` 객체가 움직이면 `Child` 객체들이 따라가는 구조.
  - **인공지능 결정 트리(Decision Tree)**: 적 캐릭터가 "플레이어를 발견했는가? -> 체력이 낮은가? -> 도망칠까?"를 판단하는 로직.

### 2. 왜 트리를 사용하나요?
트리는 데이터 간의 **상하 관계**나 **포함 관계**를 표현하기에 가장 완벽한 방법입니다. 또한, 많은 데이터를 빠르게 탐색하거나 정렬할 때도 매우 유용합니다.

## 💻 실습 예제

**미션:** 유니티에서 간단한 '스킬 노드(Skill Node)' 구조를 만들고, 부모 스킬이 활성화되어야 자식 스킬을 배울 수 있는 알고리즘을 구현하세요.

<details>
<summary>코드 보기</summary>

```csharp
using UnityEngine;
using System.Collections.Generic;

public class SkillTreeManager : MonoBehaviour
{
    // 1. 스킬 노드 정의
    [System.Serializable]
    public class SkillNode
    {
        public string skillName;
        public bool isUnlocked = false; // 현재 스킬 해금 여부
        public SkillNode parentSkill;    // 부모 스킬 (선행 조건)
        public List<SkillNode> childSkills = new List<SkillNode>(); // 자식 스킬들

        public SkillNode(string name, SkillNode parent = null)
        {
            skillName = name;
            parentSkill = parent;
        }

        // 스킬 해금 시도
        public bool TryUnlock()
        {
            if (isUnlocked) return false;

            // 부모 스킬이 없거나(최상위), 부모가 이미 해금된 경우에만 가능
            if (parentSkill == null || parentSkill.isUnlocked)
            {
                isUnlocked = true;
                Debug.Log($"{skillName} 스킬이 해금되었습니다!");
                return true;
            }

            Debug.LogWarning($"{skillName}을 배우기 위한 선행 스킬이 필요합니다.");
            return false;
        }
    }

    // 2. 트리 구성 (Root -> Skill A -> Skill B)
    private SkillNode rootSkill;

    void Start()
    {
        // 최상위 스킬 (예: 기본 공격)
        rootSkill = new SkillNode("기본 공격");
        rootSkill.isUnlocked = true; // 시작부터 해금

        // 1단계 하위 스킬
        SkillNode powerStrike = new SkillNode("강한 일격", rootSkill);
        rootSkill.childSkills.Add(powerStrike);

        // 2단계 하위 스킬
        SkillNode whirlwind = new SkillNode("회오리 베기", powerStrike);
        powerStrike.childSkills.Add(whirlwind);

        // 테스트 시도
        whirlwind.TryUnlock(); // 실패 (강한 일격이 필요함)
        powerStrike.TryUnlock(); // 성공
        whirlwind.TryUnlock(); // 성공
    }
}
```
