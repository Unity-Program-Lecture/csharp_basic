# 🚀 [알고리즘 01] 게임 수학의 기초: 벡터(Vector)

학습 목표: 유니티 게임 개발의 가장 핵심적인 수학적 도구인 '벡터'의 개념을 이해하고, 이를 이용해 캐릭터의 이동과 방향을 제어하는 방법을 배웁니다.

---

## 💡 개념 설명 (NCS 알고리즘: 좌표계와 위치 계산)

### 1. 벡터(Vector)란 무엇인가요?
벡터는 단순히 '숫자들의 묶음'이지만, 게임 속에서는 **"어디로(방향)"** 가고 있고, **"얼마나 세게(크기)"** 가고 있는지를 나타내는 화살표와 같습니다.

- **일상 비유**: "동쪽으로(방향) 5km(크기) 이동해라"라는 명령 자체가 하나의 벡터입니다.
- **유니티에서의 벡터**: `Vector3(x, y, z)`는 3차원 공간상의 한 점이기도 하지만, 원점(0,0,0)에서 그 점까지 이어지는 화살표이기도 합니다.

### 2. 왜 벡터가 알고리즘의 시작인가요?
게임 속 모든 움직임은 수학적 알고리즘으로 처리됩니다. 캐릭터가 적을 추적하거나, 총알이 날아가는 궤적을 계산할 때 벡터 연산(더하기, 빼기)이 필수적이기 때문입니다.

- **벡터의 뺄셈 (B - A)**: 점 A에서 점 B로 향하는 **방향**을 구할 수 있습니다. (추격 알고리즘의 핵심!)
- **정규화 (Normalization)**: 화살표의 길이를 1로 만듭니다. 순수하게 '어느 쪽'인지만 남기고 싶을 때 사용합니다.

---

## 💻 실습 예제

**미션:** 유니티에서 플레이어가 목표 지점(Target)을 향해 일정한 속도로 부드럽게 이동하는 알고리즘을 구현하세요.

<details>
<summary>코드 보기</summary>

```csharp
using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    public Transform target; // 이동 목표
    public float speed = 5.0f; // 이동 속도

    void Update()
    {
        if (target == null) return;

        // 1. 방향 벡터 계산 (목표 위치 - 현재 위치)
        Vector3 direction = target.position - transform.position;

        // 2. 거리가 아주 가까우면 이동 중지
        if (direction.magnitude > 0.1f)
        {
            // 3. 방향 정규화 (순수한 방향 정보만 추출)
            Vector3 normalizedDirection = direction.normalized;

            // 4. 이동 알고리즘 적용 (위치 = 현재위치 + 방향 * 속도 * 시간)
            transform.position += normalizedDirection * speed * Time.deltaTime;

            // 5. 목표를 바라보게 회전 (선택 사항)
            transform.forward = normalizedDirection;
        }
    }
}
```

</details>
