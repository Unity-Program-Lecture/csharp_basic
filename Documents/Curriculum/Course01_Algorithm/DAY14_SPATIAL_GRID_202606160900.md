## 💡 개념 설명: 공간 분할이란?
- **비유: 도서관의 책꽂이**
    - 도서관에서 책을 찾을 때, 1층부터 모든 책을 하나하나 확인(O(N))하면 너무 오래 걸립니다.
    - 하지만 '소설', '역사', '과학' 등 구역(Grid)을 나눠두면, 내가 찾는 책이 있는 구역만 확인하면 됩니다.
- **게임에서의 활용:**
    - 화면에 1,000마리의 몬스터가 있을 때, 서로의 거리를 모두 계산하면 1,000,000번의 연산이 필요합니다(N^2).
    - 맵을 격자로 나누고 "같은 칸 혹은 옆 칸에 있는 애들만 검사해!"라고 제한하면 연산량이 획기적으로 줄어듭니다.

## 💻 실습 예제: Simple Grid System

**미션:** 객체의 좌표를 입력받아 어떤 Grid 칸에 속하는지 계산하고, 해당 칸에 있는 다른 객체들을 반환하는 로직을 작성하세요.

<details>
<summary>코드 보기</summary>

```csharp
using UnityEngine;
using System.Collections.Generic;

public class SpatialGrid : MonoBehaviour
{
    public float cellSize = 5f;
    private Dictionary<Vector2Int, List<Transform>> grid = new Dictionary<Vector2Int, List<Transform>>();

    // 객체를 위치에 따라 그리드에 등록
    public void UpdateObject(Transform obj)
    {
        Vector2Int gridPos = GetGridPos(obj.position);
        
        if (!grid.ContainsKey(gridPos))
            grid[gridPos] = new List<Transform>();
            
        grid[gridPos].Add(obj);
    }

    // 좌표를 그리드 인덱스로 변환 (핵심 알고리즘)
    public Vector2Int GetGridPos(Vector3 worldPos)
    {
        int x = Mathf.FloorToInt(worldPos.x / cellSize);
        int z = Mathf.FloorToInt(worldPos.z / cellSize);
        return new Vector2Int(x, z);
    }

    // 주변 칸(9칸)에 있는 객체들만 가져오기
    public List<Transform> GetNearby(Vector3 worldPos)
    {
        List<Transform> nearby = new List<Transform>();
        Vector2Int center = GetGridPos(worldPos);

        for (int x = -1; x <= 1; x++)
        {
            for (int z = -1; z <= 1; z++)
            {
                Vector2Int targetPos = center + new Vector2Int(x, z);
                if (grid.ContainsKey(targetPos))
                    nearby.AddRange(grid[targetPos]);
            }
        }
        return nearby;
    }
}
```
