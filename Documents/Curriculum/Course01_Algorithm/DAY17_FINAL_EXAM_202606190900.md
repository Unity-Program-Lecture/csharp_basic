## 💻 최종 실전 미션: 미니 던전 생존 시스템

**미션:** 아래 명세에 맞는 시스템 구조를 설계하세요. (코드가 아닌 '알고리즘 선택 이유'가 중요합니다.)

1. **지형:** 매번 접속할 때마다 다른 동굴 지형이 생성되어야 함.
2. **성능:** 500개의 화살이 동시에 날아다녀도 프레임이 유지되어야 함.
3. **AI:** 몬스터는 플레이어를 감지하면 가장 빠른 길로 쫓아와야 하며, 체력이 낮으면 도망가거나 회복 아이템을 찾아야 함.
4. **최적화:** 수많은 몬스터들이 서로 충돌 연산을 할 때 부하를 최소화해야 함.

<details>
<summary>해답 가이드 보기</summary>

- **지형 생성:** 절차적 생성(Procedural Generation) - Perlin Noise 또는 Cellular Automata 활용.
- **화살 성능:** 오브젝트 풀링(Object Pooling) - Queue를 사용하여 재사용.
- **몬스터 이동:** A* 알고리즘 - 장애물을 피하는 최단 경로 탐색.
- **몬스터 AI:** Behavior Tree - 상태 전이(Selector/Sequence)를 통한 복합 판단.
- **충돌 최적화:** 공간 분할(Spatial Partitioning) - Grid 기반으로 주변 객체만 검사.
