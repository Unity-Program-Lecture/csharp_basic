# 🚀 [알고리즘 10] 똑똑한 길찾기: A* (A-Star) 알고리즘 기초

학습 목표: 게임 엔진에서 가장 널리 사용되는 길찾기 알고리즘인 A*의 원리를 이해하고, '휴리스틱(Heuristic)' 점수를 계산하여 탐색 범위를 획기적으로 줄이는 방법을 배웁니다.

---

## 💡 개념 설명 (NCS 알고리즘: 휴리스틱 경로 탐색)

### 1. 다익스트라보다 똑똑한 A*?
다익스트라는 모든 방향을 공평하게 탐색하지만, A*는 **"목적지가 이쪽 방향이니까 이쪽을 먼저 보자!"**라는 똑똑한 추측(Heuristic)을 가미합니다.

- **F = G + H**
  - **G (Go)**: 시작점에서 현재 칸까지 오는데 걸린 실제 비용 (다익스트라와 동일)
  - **H (Heuristic)**: 현재 칸에서 목적지까지 얼마나 남았을지 예상하는 비용 (직선 거리 등)
  - **F (Final)**: G와 H를 더한 최종 점수. 이 점수가 낮은 칸부터 먼저 탐색합니다.

### 2. 휴리스틱(Heuristic)이란?
"정확하지는 않지만 대략 이럴 것이다"라는 경험적인 추측입니다. 게임 길찾기에서는 보통 **맨해튼 거리(Manhattan Distance)**를 많이 사용합니다.

- **일상 비유**: 모르는 길을 찾을 때, 지도를 보지 않더라도 "일단 북쪽이니까 계속 북쪽으로 가보자"라고 결정하는 것과 비슷합니다.

## 💻 실습 예제

**미션:** A* 알고리즘의 핵심인 노드(Node) 구조를 설계하고, 두 지점 사이의 맨해튼 거리(H 점수)를 계산하는 함수를 작성하세요.

<details>
<summary>코드 보기</summary>

```csharp
using UnityEngine;
using System;

public class AStarBase : MonoBehaviour
{
    // A* 탐색을 위한 노드 클래스
    public class Node
    {
        public Vector2Int pos;
        public int gScore; // 시작점부터의 거리
        public int hScore; // 목적지까지의 예상 거리
        public int fScore => gScore + hScore; // 최종 점수

        public Node parent; // 경로 역추적을 위한 부모 노드 참조

        public Node(Vector2Int position)
        {
            this.pos = position;
        }
    }

    // 맨해튼 거리 계산 알고리즘 (H 점수)
    // 가로 차이 + 세로 차이의 절댓값 합
    public int GetManhattanDistance(Vector2Int start, Vector2Int end)
    {
        int xDist = Mathf.Abs(start.x - end.x);
        int yDist = Mathf.Abs(start.y - end.y);
        return xDist + yDist;
    }

    void Start()
    {
        Vector2Int playerPos = new Vector2Int(0, 0);
        Vector2Int goalPos = new Vector2Int(5, 3);
        
        int h = GetManhattanDistance(playerPos, goalPos);
        Debug.Log($"목표까지의 예상 거리(H): {h}");
    }
}
```
