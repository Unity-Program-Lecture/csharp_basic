# 🚀 [알고리즘 12] AI의 뇌 만들기: 유한 상태 머신 (FSM)

학습 목표: 캐릭터의 행동 패턴을 효율적으로 관리하는 '유한 상태 머신(Finite State Machine)'의 개념을 이해하고, 몬스터가 플레이어를 추적하고 공격하는 기본 AI 로직을 구현합니다.

---

## 💡 개념 설명 (NCS 알고리즘: 상태 머신을 이용한 AI 제어)

### 1. FSM (유한 상태 머신)이란?
캐릭터가 가질 수 있는 '상태'를 정의하고, 특정 '조건'에 따라 다른 상태로 전환(Transition)하는 설계 방식입니다.

- **상태(State)**: 배회(Patrol), 추적(Chase), 공격(Attack), 사망(Die) 등
- **전이(Transition)**: "플레이어가 감지 범위 안에 들어오면 배회에서 추적으로 바꾼다"

### 2. 왜 FSM을 사용하나요?
만약 `if-else`문으로만 AI를 만든다면 상태가 많아질수록 코드가 복잡해져서 관리가 불가능해집니다. FSM은 상태별로 로직을 분리하여 **"지금 내가 무엇을 해야 하는가"**에만 집중하게 해줍니다.

- **일상 비유**: 신호등(빨강 -> 노랑 -> 초록), 자판기(동전 대기 -> 제품 선택 -> 거스름돈)

## 💻 실습 예제

**미션:** 유니티에서 `enum`과 `switch`문을 사용하여 몬스터의 3가지 상태(Idle, Chase, Attack)를 관리하는 기초 FSM을 구현하세요.

<details>
<summary>코드 보기</summary>

```csharp
using UnityEngine;

public class MonsterAI : MonoBehaviour
{
    // 1. 상태 정의
    public enum State { Idle, Chase, Attack }
    public State currentState = State.Idle;

    public Transform player;
    public float chaseRange = 5.0f;
    public float attackRange = 1.5f;

    void Update()
    {
        // 2. 상태별 로직 실행
        switch (currentState)
        {
            case State.Idle:
                UpdateIdle();
                break;
            case State.Chase:
                UpdateChase();
                break;
            case State.Attack:
                UpdateAttack();
                break;
        }
    }

    void UpdateIdle()
    {
        float dist = Vector3.Distance(transform.position, player.position);
        if (dist < chaseRange) currentState = State.Chase; // 추적 상태로 전환
    }

    void UpdateChase()
    {
        float dist = Vector3.Distance(transform.position, player.position);
        
        if (dist <= attackRange)
        {
            currentState = State.Attack; // 공격 상태로 전환
        }
        else if (dist > chaseRange)
        {
            currentState = State.Idle; // 다시 대기 상태로
        }
        else
        {
            // 플레이어를 향해 이동 (A* 결과나 단순 이동 알고리즘 사용 가능)
            transform.position = Vector3.MoveTowards(transform.position, player.position, Time.deltaTime * 2f);
        }
    }

    void UpdateAttack()
    {
        float dist = Vector3.Distance(transform.position, player.position);
        if (dist > attackRange) currentState = State.Chase;
        
        Debug.Log("플레이어 공격 중!");
    }
}
```
