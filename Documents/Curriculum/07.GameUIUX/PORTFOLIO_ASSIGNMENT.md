# 게임 UI/UX 프로그래밍 포트폴리오 과제

- 교과목: 게임 UI/UX 프로그래밍
- NCS 능력단위: `0803020529_18v4 게임 UIUX 프로그래밍`
- 평가 환경: Unity 6, C#, UGUI, TextMeshPro, Input System

## 과제 개요

Unity 6 프로젝트에서 플레이 가능한 작은 UI/UX 프로토타입을 제작합니다. 목표는 큰 게임을 완성하는 것이 아니라, NCS 기준의 UI/UX 설계, 요소 구현, UI 프레임워크 구현, 체크리스트 검증을 한 씬 안에서 확인할 수 있게 만드는 것입니다.

## 필수 구현 범위

1. UI/UX 설계 문서
   - 화면 목록, 입력 방식, 화면 전환 흐름, UI Prefab 후보를 정리합니다.
   - 기준 해상도와 Canvas Scaler 설정을 명시합니다.

2. HUD
   - 체력, 점수, 남은 시간, 목표 안내 중 3개 이상을 UGUI로 표시합니다.
   - 표시 값은 실제 스크립트 변수와 연결되어야 합니다.

3. 메뉴 시스템
   - 타이틀 화면, 플레이 HUD, 일시정지 메뉴, 결과 화면 중 3개 이상을 구현합니다.
   - 버튼을 통해 화면 전환이 가능해야 합니다.

4. 입력 인터페이스
   - 마우스 클릭으로 UI를 조작할 수 있어야 합니다.
   - 키보드 또는 게임패드로 메뉴 이동, Submit, Cancel 중 2개 이상을 확인할 수 있어야 합니다.

5. UI 프레임워크 요소
   - 반복 사용 가능한 UI Prefab을 2개 이상 만듭니다.
   - 예: MenuButton, GaugeBar, ToastMessage, ConfirmPopup, ItemSlot

6. UI/UX 피드백
   - 버튼 상태 변화, 알림 메시지, 비활성화 표시, 색 변화 중 2개 이상을 구현합니다.

7. 체크리스트 검증
   - 해상도, 입력, 화면 전환, 데이터 연결을 확인한 자체 체크리스트를 작성합니다.

## 권장 프로젝트 예시

| 주제 | 설명 |
| :--- | :--- |
| 미니 액션 HUD | 체력, 점수, 시간, 일시정지, 결과 화면을 구현합니다. |
| 인벤토리 UI | 아이템 슬롯, 선택 표시, 아이템 설명, 사용 버튼을 구현합니다. |
| 설정 메뉴 | 사운드 슬라이더, 해상도 선택, 적용/취소 버튼을 구현합니다. |
| 퀘스트 트래커 | 목표 안내, 완료 알림, 결과 화면을 구현합니다. |

## 제출 산출물

- Unity 6 프로젝트 또는 프로젝트 폴더
- 구현 씬 1개 이상
- 주요 UI 스크립트
- 재사용 UI Prefab
- UI/UX 설계 문서
- 자체 체크리스트
- 실행 화면 캡처 2장 이상

## 마무리 기준

좋은 결과물은 화면이 화려한 프로젝트가 아니라, 플레이어가 무엇을 해야 하는지 알 수 있고, 입력했을 때 즉시 반응하며, 게임 상태가 UI에 정확히 표시되는 프로젝트입니다. UI는 게임의 안내판이면서 조작 장치입니다. 안내판이 읽히고, 조작 장치가 믿을 수 있게 동작하면 기본 UX는 이미 절반 이상 완성된 것입니다.
