# 게임 UI/UX 프로그래밍 운영 계획

이 문서는 `26국기_교수계획서.pdf`의 `0803020529_24v5 게임 UI/UX 프로그래밍` 주요 학습내용을 Unity 6 학습 문서에 배치한 운영표입니다. 수업은 하루 6시간, 최대 4교시로 운영하며 1교시는 90분을 기준으로 합니다.

## 교수계획서 반영표

| 교수계획서 주요 학습내용 | 반영 문서 | 학생 산출물 또는 확인 방법 |
| :--- | :--- | :--- |
| UI/UX 분석과 계획 수립 | DAY 01 | 화면·입력·전환 흐름 목록 |
| UI/UX 리소스 설계 | DAY 01 | 글꼴, 버튼 상태, 아이콘, 패널 규칙 |
| UI/UX 콘셉트 아이디어 도출 | DAY 01 | 플레이어 경험 중심의 콘셉트 문장 |
| UI/UX 아키텍처 설계 | DAY 01, DAY 05 | Canvas, 화면, 데이터, 입력, UIManager 구조 |
| GUI 디자인 가이드 이해와 구현 가능성 검토 | DAY 02 | 가이드 표, 해상도·입력 테스트, 설계 변경 판단 |
| GUI 프로세스 이해와 설계 변경 판단 | DAY 02, DAY 03, DAY 04 | 레이아웃·메뉴·입력 흐름의 수정 기록 |
| 상세 체크리스트 작성과 단위 테스트 | DAY 02, DAY 03, DAY 04, DAY 06 | 요소별 기대 결과, 실제 결과, 다시 확인한 기록 |
| UI 구현 표준에 따른 요소 제작 | DAY 02~DAY 04 | UGUI, TextMeshPro, EventSystem, Input System 기반 HUD·메뉴·입력 |
| UI 레이아웃과 사용자 인터페이스 환경 구성 | DAY 02~DAY 04 | 해상도 대응 HUD, 메뉴 Panel, Navigation |
| UI 프레임워크 아키텍처 설계와 구현 | DAY 05~DAY 06 | Prefab, UIManager, Toast 또는 Popup 통합 |

## 일자별 4교시 운영

| 일자 | 1교시 | 2교시 | 3교시 | 4교시 |
| :--- | :--- | :--- | :--- | :--- |
| DAY 01 | UI/UX와 사용자 행동 분석 | 화면·입력·컨트롤·커스텀 UI 추출 | 리소스 규칙과 UX 콘셉트 작성 | 아키텍처와 설계서 완성 |
| DAY 02 | GUI 디자인 가이드와 구현 가능성 | Canvas·Canvas Scaler 설정 | RectTransform·Anchor·Pivot | HUD 구현과 요소별 테스트 기록 |
| DAY 03 | 메뉴 화면 흐름 설계 | EventSystem과 Button 연결 | Panel 전환 구현 | 메뉴 단위 테스트 |
| DAY 04 | Input System과 UI 입력 구성 | Navigate·Submit·Cancel 연결 | Pause 입력 구현 | 키보드·게임패드 Navigation 테스트 |
| DAY 05 | UI 프레임워크 역할 분리 | UI Prefab 제작 기준 | Toast 또는 Popup 구현 | UIManager와 인터페이스 문서화 |
| DAY 06 | HUD·메뉴·입력 통합 | 상세 체크리스트 작성 | 해상도·입력·데이터 통합 테스트 | 설계 변경 기록과 포트폴리오 정리 |

## 문서 분할 기준

현재 DAY 문서는 한 일자의 4교시를 모두 다루되, 수업 중 바로 따라 읽을 수 있는 분량입니다. 이후 한 DAY 문서가 한 화면·기능의 완성 절차를 넘어서 두 개 이상의 독립 실습을 포함하게 되면, `DAY##_A_주제.md`, `DAY##_B_주제.md`로 분할합니다. 분할해도 같은 날의 교시는 합계 4개를 넘기지 않습니다.
