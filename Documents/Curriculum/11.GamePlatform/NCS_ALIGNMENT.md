# NCS 학습 목표 연결표

이 과정은 저장소의 `NCS_Modules/LM0803020528_18v4,+LM0803020529_18v4_게임플랫폼과+UIUX+프로그래밍.pdf` 중 게임플랫폼 영역을 기준으로 구성했습니다. 해당 능력단위 코드는 `0803020528_18v4`입니다. 통합 교재에 함께 수록된 UI/UX 능력단위는 별도 교과목에서 다룹니다.

전체 목표: 사용자 측의 게임 구동이 가능한 플랫폼에서 게임이 원활하게 작동하도록 플랫폼 개발 환경을 구축하고 플랫폼 응용 프로그램을 설계·구현할 수 있다.

## 교재의 평가 의도를 수업으로 옮기기

교재에서 제시하는 평가 방법은 포트폴리오, 서술형 시험, 평가자 체크리스트입니다. 이에 맞춰 수업에서는 개발 장치와 실행 장치의 차이, 모바일 디버깅, 자료 구조와 알고리즘 설계를 다루고 오류 해결과 프로파일링 과정을 기록합니다. 실행 영상과 함께 설계 이유와 측정 기록을 남기면 게임이 동작하기까지의 학습 과정을 확인할 수 있습니다.

- 지식: 플랫폼·하드웨어·운영체제·라이브러리의 관계, 컬렉션, 비동기 로드, 빌드 결과물, 성능 지표를 설명합니다.
- 기술: 환경 구성, 입력·렌더링·사운드 테스트, 자료 구조 설계, 코딩, 로그 분석, 측정과 수정을 수행합니다.
- 태도: 확인한 사실과 아직 확인하지 못한 내용을 구분하고, 재현 절차와 변경 이유를 기록합니다.

위의 지식·기술·태도 항목은 학습모듈의 필요 지식, 수행, 교수학습, 평가 내용을 수업에 맞게 재구성한 것으로, 공식 수행준거의 원문과는 구분됩니다.

교재에서 다루는 서버 관련 내용은 DAY 08의 HTTPS 파일 서버, DAY 09의 원격 콘텐츠 배포, DAY 13의 설정 파일 읽기 실습으로 연결합니다. 클라이언트와 설정 제공 서버의 역할, 요청과 응답의 JSON 구조, 실패 처리를 살펴봅니다. 공통 실습 게임은 오프라인으로 실행하므로 인증과 실시간 서버 구현은 추가 학습 범위로 둡니다.

## iOS 학습 범위

iOS 환경과 빌드 흐름은 참고 문서에서 비교합니다. 실습과 목표 달성 여부는 PC, Android, Web의 결과로 확인하며 iOS 실행 기록은 요구하지 않습니다. iOS 관련 내용은 참고 자료를 통해 학습한 것으로 기록합니다.
