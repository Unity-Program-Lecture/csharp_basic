# 🚀 Day 03: 판단과 반복 (제어 흐름)

오늘의 목표는 **"조건에 따라 다른 코드를 실행하고, 반복되는 일을 자동화하는 제어문을 마스터한다"**입니다.

---

## 1. 연산자 (Operator): "계산 도구"
- **산술**: `+`, `-`, `*`, `/`, `%`(나머지)
- **비교**: `==`(같다), `!=`(다르다), `>`, `<`
- **논리**: `&&`(AND: 둘 다 참), `||`(OR: 하나라도 참)

---

## 2. 조건문 (if, switch): "선택의 순간"
- **if-else**: "만약 ~라면 A를 하고, 아니면 B를 해라!"
- **switch**: "상태가 1번이면 이걸 하고, 2번이면 저걸 해라!" (딱 떨어지는 값에 유리)

---

## 3. 반복문 (for, while): "반복의 마법"
- **for**: 반복 횟수가 정해져 있을 때 (예: 10번 반복)
- **while**: 조건이 참인 동안 무한히 반복할 때 (예: 플레이어가 살아있는 동안)

---

## 💻 실습 예제: 홀짝 판별기와 숫자 세기
**미션:** 1부터 10까지 숫자를 출력하면서, 그 숫자가 홀수인지 짝수인지 옆에 표시해 보세요.

<details>
<summary>코드 보기</summary>

```csharp
using System;

class Program
{
    static void Main()
    {
        for (int i = 1; i <= 10; i++)
        {
            if (i % 2 == 0)
            {
                Console.WriteLine($"{i} : 짝수");
            }
            else
            {
                Console.WriteLine($"{i} : 홀수");
            }
        }
    }
}
```

</details>
