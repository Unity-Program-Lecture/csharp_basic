# 🚀 Day 14: 기록과 비동기 (File I/O & Async)

오늘의 목표는 "**데이터를 영구적으로 저장하는 법과 프로그램이 멈추지 않게 뒤에서 작업하는 비동기를 익히고 최종 프로젝트를 완성한다**"입니다.

---

## 1. 파일 입출력 (File I/O): "기억을 기록으로"
변수에 담긴 데이터는 프로그램을 끄면 사라집니다. 이를 텍스트 파일(`.txt`)로 저장하면 영구 보관이 가능합니다.
- **`File.WriteAllText`**: 파일로 내보내기 (저장)
- **`File.ReadAllText`**: 파일에서 가져오기 (불러오기)
- **`File.Exists`**: 파일이 실제로 있는지 확인하기

---

## 2. 비동기 (Async/Await): "기다리는 동안 딴짓하기"
엄청나게 큰 파일을 다운로드하거나 로딩할 때, 프로그램이 멈춘 것처럼 보이지 않게 뒤에서 조용히 처리하는 기술입니다.
- **`async`**: 이 함수는 비동기로 작동한다는 표시.
- **`await`**: 이 작업이 끝날 때까지 기다리되, 그동안 다른 코드는 계속 실행하라는 뜻.

## 💻 실습 예제: 파일 저장과 비동기 인사
**미션:** 텍스트 파일을 만들고, 2초 뒤에 비동기로 저장 완료 메시지를 띄워 보세요.

<details>
<summary>코드 보기</summary>

```csharp
using System;
using System.IO;
using System.Threading.Tasks;

class Program
{
    static async Task Main()
    {
        string path = "save.txt";
        File.WriteAllText(path, "PlayerLevel: 10\nGold: 500");

        Console.WriteLine("저장 중입니다...");
        await Task.Delay(2000); // 2초 기다리기
        
        Console.WriteLine("저장이 완료되었습니다!");
        Console.WriteLine("내용: " + File.ReadAllText(path));
    }
}
```
