# DAY 03: 형식적 요소와 시스템 기준

오늘은 게임을 이루는 형식적 요소를 정리합니다. 형식적 요소는 게임을 게임답게 만드는 기본 부품입니다. 플레이어, 목표, 절차, 규칙, 자원처럼 시스템 공식과 테이블을 만들기 전에 먼저 확인해야 하는 기준입니다.

## 1. 핵심 개념: "보드게임 상자 안의 구성품 확인"

보드게임 상자를 열면 말, 카드, 주사위, 점수판, 설명서가 들어 있습니다. 각각이 어떤 역할을 하는지 모르면 게임을 시작할 수 없습니다.

디지털 게임도 마찬가지입니다. 플레이어는 누구인지, 목표는 무엇인지, 어떤 자원을 쓰는지, 어떤 규칙으로 성공과 실패가 나뉘는지 정리해야 합니다.

### 이 단어는 무슨 뜻인가요?

- **형식적 요소**: 게임을 구성하는 기본 구조입니다.
- **플레이어**: 게임에서 선택하고 행동하는 주체입니다.
- **목표**: 플레이어가 달성해야 하는 상태입니다.
- **절차**: 플레이어가 목표에 도달하기 위해 거치는 순서입니다.
- **자원**: 플레이어가 얻고 쓰고 관리하는 값입니다.
- **챌린지**: 플레이어가 넘어서야 하는 도전 요소입니다.

## 2. 형식적 요소를 정리하는 이유

형식적 요소를 정리하면 시스템 공식이 필요한 위치가 보입니다. 예를 들어 체력, 공격력, 가격, 경험치, 성공 확률처럼 숫자로 처리되는 요소는 공식이나 테이블이 필요할 가능성이 높습니다.

| 형식적 요소 | 시스템 기획에서 확인할 것 |
| :--- | :--- |
| 플레이어 | 무엇을 조작하고 선택하는가 |
| 목표 | 승리, 클리어, 성장 조건은 무엇인가 |
| 절차 | 매 턴, 매 스테이지, 매 방문마다 무엇을 하는가 |
| 규칙 | 가능/불가능, 성공/실패 기준은 무엇인가 |
| 자원 | 골드, 체력, 시간, 카드, 재료 등 관리 값은 무엇인가 |
| 챌린지 | 난이도와 위험은 어디서 생기는가 |

## 문서 실습: 형식적 요소 분석표

### 작성 예시

```text
게임 가제: 10분 던전 상점

1. 플레이어
- 플레이어의 역할: 던전 앞 상점 주인
- 플레이어가 조작하거나 선택하는 것: 판매 아이템, 제작 우선순위, 상점 업그레이드

2. 목표
- 단기 목표: 손님에게 알맞은 아이템을 판매한다.
- 장기 목표: 상점을 성장시켜 더 위험한 던전 손님을 지원한다.

3. 절차
- 손님 방문 -> 정보 확인 -> 아이템 추천 -> 판매 -> 결과 확인 -> 재료 획득 -> 상점 강화

4. 규칙
- 손님 직업과 던전 위험에 맞는 아이템일수록 만족도가 오른다.
- 보유하지 않은 아이템은 판매할 수 없다.

5. 자원
- 얻는 자원: 골드, 재료, 평판
- 쓰는 자원: 제작 재료, 업그레이드 비용
- 부족하면 생기는 문제: 아이템 제작과 상점 확장이 막힌다.

6. 챌린지
- 어려움이 생기는 지점: 손님 정보가 제한적이고 던전 위험이 다양하다.
- 플레이어가 극복하는 방법: 이전 결과를 보고 아이템 조합을 개선한다.

7. 공식이나 테이블이 필요해 보이는 요소
- 만족도 계산식, 아이템 가격표, 손님 직업별 선호 아이템표, 던전 위험 속성표
```

### 생각해보기

1. 자원이 너무 많으면 플레이어는 어떤 어려움을 느낄까요?
2. 목표가 불분명하면 게임 루프는 어떻게 흔들릴까요?
3. 형식적 요소를 먼저 정리하면 공식 작성이 쉬워지는 이유는 무엇일까요?

## 오늘의 정리

- 형식적 요소는 게임 시스템을 이루는 기본 부품입니다.
- 플레이어, 목표, 절차, 규칙, 자원, 챌린지를 정리하면 시스템의 기준이 보입니다.
- 숫자로 처리해야 하는 요소는 공식이나 테이블로 이어질 가능성이 높습니다.
