# 게임 시스템 기획 포트폴리오 과제

## 과제 개요

하나의 게임 아이디어에서 핵심 시스템 하나를 선택하고, 개발자가 구현 방향을 이해할 수 있는 시스템 기획서를 작성합니다. 이 과제는 코드 결과물이 아니라 규칙, 흐름, 공식, 데이터 테이블을 평가합니다.

## 제출 산출물

1. 코어 메카닉스 분석표
2. 시스템 흐름도 또는 텍스트 흐름도
3. 형식적 요소 분석표
4. 시스템 공식 설계서
5. 시스템 데이터 테이블
6. 최종 시스템 기획서
7. 리뷰 체크리스트와 수정 내용
8. 5분 발표용 요약 자료

## 평가 기준

| 평가 항목 | 확인 내용 |
| :--- | :--- |
| 코어 메카닉스 | 핵심 행동과 규칙이 분명한가 |
| 흐름 설계 | 시작, 입력, 처리, 조건, 출력이 정리되었는가 |
| 공식 설계 | 입력값, 출력값, 예시 계산, 상한/하한이 있는가 |
| 테이블 설계 | ID, 컬럼, 단위, 데이터 규칙이 분명한가 |
| 예외 처리 | 실패, 부족, 중복, 취소 상황을 고려했는가 |
| 전달력 | 다른 사람이 읽고 구현 방향을 이해할 수 있는가 |

## 제출 형식

- Markdown, PDF, PPT, 스프레드시트 중 하나 또는 여러 개로 제출합니다.
- 테이블은 Markdown 표, Excel, Google Sheets 중 편한 형식을 사용할 수 있습니다.
- 공식은 복잡하지 않아도 되지만 예시 계산을 반드시 포함합니다.
- 유사 게임을 참고한 경우 게임명과 참고한 요소를 적습니다.

## 발표 구성

```text
1. 게임 가제와 선택한 시스템
2. 시스템 목적
3. 코어 메카닉스
4. 기본 흐름과 조건 분기
5. 사용 공식과 예시 계산
6. 사용 데이터 테이블
7. 예외 상황과 테스트 조건
8. 리뷰 후 수정한 내용
```

## 주의사항

- 기능을 많이 넣는 것보다 하나의 시스템을 명확하게 쓰는 것이 더 중요합니다.
- 공식은 실제 계산 예시가 있어야 합니다.
- 테이블의 ID는 중복되지 않게 작성합니다.
- "적당히", "자연스럽게", "랜덤하게" 같은 표현은 가능한 한 구체적인 조건과 수치로 바꿉니다.
