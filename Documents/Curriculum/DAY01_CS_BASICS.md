# 🚀 Day 01: 프로그래밍의 시작, 변수와 상자

오늘의 목표는 "**변수가 무엇인지 이해하고, 컴퓨터가 데이터를 기억하는 단위인 비트와 바이트를 마스터한다**"입니다.

---

## 1. 변수(Variable): "데이터를 담는 상자"
프로그래밍에서 가장 먼저 배우는 것은 '기억'하는 법입니다. 변수는 메모리에 이름을 붙여 데이터를 저장하는 상자입니다.

### 💡 코드 독해 3원칙
1. **위에서 아래로**: 코드는 위에서 아래로 흐릅니다.
2. **오른쪽에서 왼쪽으로**: `age = 20`은 20을 age 상자에 넣는다는 뜻입니다.
3. **안에서 밖으로**: 괄호 안의 계산이 먼저입니다.

---

## 2. 데이터 타입의 크기: "상자의 종류"
컴퓨터는 모든 데이터를 **0과 1**(**Bit**)로 기억합니다.

- **Bit (비트)**: 전등 스위치 1개 (0 또는 1).
- **Byte (바이트)**: 비트 8개를 묶은 '서랍 한 칸'. (256가지 표현 가능)

### 📦 주요 상자 대결
- **int (4바이트)**: 약 21억까지 담는 가장 대중적인 정수 상자.
- **long (8바이트)**: 우주적인 숫자도 담는 초대형 상자.
- **float (4바이트)**: 소수점을 담는 상자 (지수/밑수 압축 방식).
- **bool (1바이트)**: 참(True) 또는 거짓(False)만 담는 상자.

---

## 3. 부호의 비밀 (Signed vs Unsigned)
- **Signed**: 맨 앞 비트를 '부호 깃발(+, -)'로 사용합니다.
- **Unsigned**: 음수를 포기하는 대신 양수를 **2배** 더 크게 담습니다. (예: `uint`)

---

## 💻 실습 예제: 내 캐릭터 정보 저장
**미션:** 이름, 나이, 키, 소지금을 변수에 담고 출력해 보세요.

<details>
<summary>코드 보기</summary>

```csharp
using System;

class Program
{
    static void Main()
    {
        string name = "Gemini";
        int age = 20;
        float height = 175.5f; // float는 뒤에 f를 붙여야 해요!
        long gold = 3000000000; // int 범위를 넘는 30억

        Console.WriteLine($"이름: {name}");
        Console.WriteLine($"나이: {age}");
        Console.WriteLine($"키: {height}cm");
        Console.WriteLine($"소지금: {gold}G");
    }
}
```

</details>
