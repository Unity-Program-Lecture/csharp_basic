# 🚀 Day 01: 변수와 메모리 (상자와 조리대)

오늘의 목표는 "**데이터를 담는 변수의 개념을 익히고, 컴퓨터가 이를 메모리에 어떻게 저장하고 처리하는지 이해한다**"입니다.

---

## 1. 변수(Variable): "데이터를 담는 상자"
프로그래밍에서 가장 먼저 배우는 것은 '기억'하는 법입니다. 변수는 메모리에 이름을 붙여 데이터를 저장하는 상자입니다.

### 💡 코드 독해 3원칙
1. **위에서 아래로**: 코드는 위에서 아래로 흐릅니다.
2. **오른쪽에서 왼쪽으로**: `age = 20`은 20을 age 상자에 넣는다는 뜻입니다.
3. **안에서 밖으로**: 괄호 안의 계산이 먼저입니다.

---

## 2. 데이터 타입의 크기: "상자의 종류"
컴퓨터는 모든 데이터를 **0과 1(Bit)**로 기억합니다.

- **int (4바이트)**: 약 21억까지 담는 가장 대중적인 정수 상자.
- **long (8바이트)**: 우주적인 숫자도 담는 초대형 상자.
- **float (4바이트)**: 소수점을 담는 상자. (뒤에 `f`를 붙임)
- **bool (1바이트)**: 참(True) 또는 거짓(False)만 담는 상자.
- **string (가변)**: 문장(텍스트)을 담는 상자. 큰따옴표(`""`)로 감쌉니다.

---

## 3. 실행 원리와 메모리 (요리사와 조리대)
- **CPU (요리사)**: 계산하고 명령을 실행합니다.
- **메모리 (조리대)**: 요리 재료(데이터)와 레시피(코드)를 잠시 올려두는 곳입니다.

### 🏢 스택 (Stack) vs 🏗️ 힙 (Heap)
- **스택**: 빠르고 자동입니다. 기본 숫자(`int`, `bool` 등)를 담습니다.
- **힙**: 넓지만 관리가 필요합니다. 실제 객체(`class`, `string`)를 담습니다.

### 🍎 값 vs 📺 참조
- **값 타입**: 상자 안에 진짜 데이터가 있음 (복사하면 물건이 두 개).
- **참조 타입**: 상자 안에 **주소(리모컨)**가 있음 (복사하면 리모컨이 두 개).

---

## 💻 실습 예제: 내 캐릭터 정보와 참조 확인
```csharp
using System;

class Monster { public int hp = 100; }

class Program
{
    static void Main()
    {
        // 1. 변수 선언
        string name = "Gemini";
        int age = 20;
        
        // 2. 참조 타입 확인
        Monster m1 = new Monster();
        Monster m2 = m1; 
        m2.hp = 0;
        
        Console.WriteLine($"이름: {name}, 나이: {age}");
        Console.WriteLine($"m1 HP: {m1.hp}"); // 결과: 0 (리모컨 복사 효과)
    }
}
```
