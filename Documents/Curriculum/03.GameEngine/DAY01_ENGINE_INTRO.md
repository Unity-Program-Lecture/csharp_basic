# 🚀 Day 01: 게임 엔진 개론 (Unity Engine Intro)

오늘의 목표는 "**상용 게임 엔진인 유니티(Unity)와 언리얼(Unreal)의 특징을 비교하고, 유니티 에디터의 기본 레이아웃과 작업 흐름을 익힌다**"입니다.

---

## 1. 상용 게임 엔진의 이해
게임 엔진은 게임 개발에 필요한 핵심 기능(렌더링, 물리, 사운드, 네트워킹 등)을 미리 만들어 놓은 소프트웨어 프레임워크입니다.

### 📍 유니티(Unity) vs 언리얼(Unreal)
| 특징 | 유니티 (Unity) | 언리얼 (Unreal) |
| :--- | :--- | :--- |
| **주요 언어** | C# | C++, Blueprints |
| **강점** | 모바일, 2D/3D 범용성, 쉬운 러닝커브 | 고퀄리티 그래픽, 대규모 오픈월드 |
| **타겟** | 인디 게임부터 대형 프로젝트까지 | AAA급 대형 프로젝트 중심 |

---

## 2. 유니티 에디터 구성 요소
유니티 작업의 80%는 다음 5가지 창에서 이루어집니다.

1. **Hierarchy (계층 구조)**: 현재 장면에 있는 모든 물체(GameObject)의 목록.
2. **Scene (장면)**: 물체를 직접 배치하고 조작하는 3D 작업 공간.
3. **Game (게임 화면)**: 실제 플레이어가 보게 될 최종 화면.
4. **Inspector (속성)**: 선택한 물체의 상세 정보(Component)를 수정하는 곳.
5. **Project (프로젝트)**: 게임에 사용될 모든 파일(Asset)을 관리하는 탐색기.

---

## 💻 실습 예제: 첫 번째 유니티 프로젝트 생성
1. **Unity Hub**를 실행하고 새 프로젝트(3D Core 템플릿)를 생성합니다.
2. **Cube**와 **Plane**을 생성하여 바닥과 상자를 배치해 봅니다.
3. **Q, W, E, R, T** 단축키를 사용하여 물체를 이동, 회전, 크기 조절해 봅니다.
