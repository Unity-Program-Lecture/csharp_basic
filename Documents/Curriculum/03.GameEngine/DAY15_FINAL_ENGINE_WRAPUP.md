# 🚀 Day 15: 엔진 프로그래밍 최종 통합 (Final Wrap-up)

오늘의 목표는 "**2주간 익힌 엔진 핵심 기능들을 하나로 모아 작동하는 프로토타입을 완성하고, 전체 학습 내용을 포트폴리오로 정리한다**"입니다.

---

## 1. 최종 프로토타입 통합 시나리오
지금까지 배운 기능들을 하나의 씬(Scene)에 결합합니다.
- **지형/환경**: 3일차에 만든 Terrain과 5일차의 Lighting.
- **기능**: 6일차의 스크립트 주기와 8일차의 물리 로직.
- **편의성**: 11일차의 UI 시스템과 12일차의 사운드/이펙트.

---

## 2. 엔진 응용 프로그래밍의 문서화 (교재 핵심)
- **기술 문서 작성**: 내가 구현한 코드의 구조와 플러그인 사용 내역을 정리합니다.
- **향후 수정 방향**: 현재 프로토타입의 한계와 고도화 계획을 수립합니다.

---

## 💻 실습 예제: 프로토타입 최종 검검 및 빌드
1. **Build Settings**에서 대상 플랫폼(PC 또는 Android)을 선택합니다.
2. 모든 씬과 리소스가 누락되지 않았는지 확인합니다.
3. **Build** 버튼을 눌러 실행 파일(`.exe` 또는 `.apk`)을 생성합니다.
4. 실제 실행 환경에서 모든 상호작용이 정상 작동하는지 최종 테스트합니다.
