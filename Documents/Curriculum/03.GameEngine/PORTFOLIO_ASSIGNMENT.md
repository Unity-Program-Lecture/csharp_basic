# 게임 엔진 포트폴리오 과제

- 대상 과정: `03.GameEngine`
- 평가 환경: Unity 6, C#
- 권장 범위: 학습 시간 안에 완성 가능한 단일 Unity 6 미니 프로젝트
- 연계 방식: `02.Algorithm` 과정 결과물을 이어서 제작할 수 있음

## 과제명

Unity 엔진 기능 기반 포트폴리오 제작

## 과제 목표

Unity 6의 기본 프로젝트 구조, 씬 구성, 오브젝트 계층, 컴포넌트, 리소스, 조명, 머티리얼, 애니메이션, UI, 사운드, VFX, 물리 Trigger 중 필요한 요소를 활용해 실행 가능한 게임 엔진 기능 기반 포트폴리오를 제출합니다.

이 과제는 완성된 게임 클라이언트를 요구하지 않습니다. 사용자가 직접 조작하는 완성형 플레이 구조보다 Unity 엔진 기능을 활용해 장면과 기능을 구성하는 능력을 확인합니다.

## 필수 구현

1. Unity 6 씬 구성

   실행 가능한 Unity 6 씬을 구성합니다. 씬 안에는 시작 위치, 주요 공간, 확인 가능한 오브젝트가 포함되어야 합니다.

2. GameObject와 Component 구조 정리

   프로젝트의 주요 오브젝트를 `Hierarchy` 안에서 의도에 맞게 배치합니다. 각 오브젝트에는 역할에 맞는 `Component`를 적용하고, 이름만으로도 대략적인 용도를 파악할 수 있도록 정리합니다.

3. 레벨 또는 플레이 공간 제작

   간단한 레벨, 방, 통로, 필드, 훈련장, 퍼즐 공간 중 하나 이상을 제작합니다. 공간은 단순 배치가 아니라 사용자가 장면의 구조를 이해할 수 있는 형태여야 합니다.

4. 카메라와 Game View 구성

   `Main Camera`를 배치하고 위치, 회전, 투영 방식, 시야 범위를 조정하여 주요 공간과 오브젝트가 Game View에서 확인되도록 구성합니다.

5. 조명과 머티리얼 적용

   조명과 머티리얼을 사용하여 장면의 분위기, 구역 구분, 오브젝트 성격 중 하나 이상을 표현합니다. 기본 오브젝트만 배치한 상태로 제출하지 않습니다.

6. 리소스와 에셋 관리

   프로젝트에 사용한 리소스, 프리팹, 머티리얼, 사운드, 이미지, VFX 파일 등을 폴더 구조 안에서 정리합니다. 외부 에셋을 사용할 경우 프로젝트 안에서 사용 위치를 확인할 수 있어야 합니다.

7. 이동 또는 경로 시스템 적용

   `CharacterController`, `NavMeshAgent`, `NavMeshSurface` 중 하나 이상을 사용해 캐릭터 이동, 목표 지점 이동, 이동 가능 영역 확인 중 하나를 구현합니다.

8. 엔진 기능 적용

   다음 항목 중 최소 2개 이상을 실제 기능으로 적용합니다.

   - Animation 또는 Animator
   - UI
   - 사운드
   - VFX
   - 물리 Trigger

9. 실행 결과 확인

   프로젝트를 실행했을 때 구현된 장면과 기능을 확인할 수 있어야 합니다. 단순 파일 제출이나 미완성 씬만으로는 제출 기준을 충족하지 않습니다.

## 선택 구현

다음 항목은 필수는 아니지만 프로젝트 완성도를 높이기 위해 권장합니다.

1. 버튼, 문, 발판, 수집물 등 간단한 상호작용 오브젝트
2. 목표 지점 또는 시연 순서가 드러나는 공간 구성
3. 이동이나 상호작용에 반응하는 애니메이션, UI, 사운드, VFX 피드백
4. 외부 에셋과 직접 제작한 리소스의 폴더 구분
5. `02.Algorithm` 과정에서 만든 규칙이나 아이디어의 Unity 장면화

## 유의 사항

`Input System`을 활용한 본격적인 입력 구조와 플레이어 조작은 `04.GameClient` 과정에서 중점적으로 다룹니다. 이 과제에서 간단한 테스트 입력을 사용할 수는 있으나, 입력 시스템 자체를 핵심 평가 요소로 보지 않습니다.

기존 `02.Algorithm` 과정 결과물을 이어서 제작하는 경우에도 본 과정의 필수 구현 요소를 새롭게 충족해야 합니다.
