# 🚀 Day 09: 외부 플러그인과 확장성 (Plugins & Package Manager)

오늘의 목표는 "**유니티의 확장 시스템인 패키지 매니저를 이해하고, 외부 플러그인을 설치하여 엔진의 기능을 확장하는 법을 익힌다**"입니다.

---

## 1. 패키지 매니저 (Package Manager)
유니티의 기능을 모듈 단위로 관리하는 도구입니다.
- **Unity Registry**: 유니티 공식 지원 패키지. (Input System, ProBuilder 등)
- **Built-in**: 엔진 기본 탑재 기능.
- **My Assets**: 에셋 스토어에서 구매/다운로드한 목록.

---

## 2. 플러그인 (Plugin): "주문식 기능 추가" (교재 핵심)
엔진에 기본적으로 없는 기능을 서드파티 개발자가 만들어 제공하는 것입니다.
- **장점**: 개발 시간을 획기적으로 단축할 수 있습니다.
- **주의**: 플러그인 간 충돌이나 버전 호환성을 확인해야 합니다.

---

## 💻 실습 예제: 새로운 입력 시스템(Input System) 설치 및 설정
1. **Window > Package Manager**를 엽니다.
2. **Input System** 패키지를 설치합니다.
3. 프로젝트 설정에서 활성화하고, 기존 `InputManager` 방식과의 차이점을 이해합니다.

---

1. **문제:** 유니티에서 필요한 기능을 모듈 형태로 선택하여 설치하고 관리하는 창의 이름은?
   - **정답:** 패키지 매니저 (Package Manager)
2. **문제:** 엔진이 기본으로 제공하지 않는 특정 기능을 추가하기 위해 설치하는 외부 소프트웨어 모듈을 무엇이라 합니까?
   - **정답:** 플러그인 (Plugin)
