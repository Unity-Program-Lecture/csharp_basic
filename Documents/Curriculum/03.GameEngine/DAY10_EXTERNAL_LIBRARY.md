# 🚀 Day 10: 에셋 스토어와 외부 SDK 연동 (Asset Store & SDKs)

오늘의 목표는 "**유니티 에셋 스토어를 활용하여 리소스를 확보하고, 외부 SDK를 연동하여 프로젝트를 고도화하는 실무 프로세스를 익힌다**"입니다.

---

## 1. 유니티 에셋 스토어 (Asset Store)
전 세계 개발자들이 만든 모델링, 사운드, 코드, 도구 등을 공유하고 판매하는 마켓입니다.

---

## 2. SDK (Software Development Kit)
특정 서비스(예: 광고, 결제, 맵, SNS)를 연동하기 위해 제공되는 개발 도구 모음입니다.
- **유니티 연동**: 보통 `.unitypackage` 형태로 제공되며, 에셋 스토어나 개발자 홈페이지에서 내려받아 Import 합니다.

---

## 💻 실습 예제: 외부 리소스 라이브러리 구성 (교재 응용)
1. 에셋 스토어에서 무료 캐릭터 모델링과 애니메이션 패키지를 다운로드합니다.
2. 프로젝트에 **Import** 하고 폴더 구조를 정리합니다.
3. 다운로드한 모델을 씬에 배치하고 기본 애니메이션이 동작하는지 확인합니다.

---

## ✍️ 평가 문항 대비 퀴즈
1. **문제:** 개발에 필요한 3D 모델, 스크립트, 사운드 등을 자유롭게 내려받거나 구매할 수 있는 유니티 전용 마켓의 이름은?
   - **정답:** 에셋 스토어 (Asset Store)
2. **문제:** 특정 플랫폼의 기능을 게임에 넣기 위해 해당 업체에서 제공하는 개발 도구 꾸러미의 약칭은?
   - **정답:** SDK (Software Development Kit)
