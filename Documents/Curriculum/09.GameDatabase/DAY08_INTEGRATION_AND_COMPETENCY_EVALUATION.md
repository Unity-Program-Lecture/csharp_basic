# 8일차: 통합 테스트와 능력단위 평가 준비 (6교시)

8일차에는 능력단위 평가 전에 통합 점검을 진행합니다. 새 개념을 추가하지 않고, 게임 데이터베이스 설계, 관계형 DB·문서형 NoSQL DB 관리 프로그램, 트랜잭션, 롤백, Unity의 읽기 전용 조회 결과를 각각 확인합니다. 서로 연결하는 코드를 작성하지 않은 기능을 하나의 실행 흐름으로 간주하지 않습니다.

## 1. 통합 점검: 저장과 화면 표시의 역할 구분

```text
1. Player와 Item, Inventory를 설계한다.
2. C# 콘솔 프로그램에서 SQLite 골드·인벤토리 구매와 롤백을 확인한다.
3. LiteDB에서는 별도의 퀘스트 진행 문서를 생성·수정·조회한다.
4. Unity에서는 SQLite `Item` 표의 이름·가격을 읽기 전용으로 표시한다.
5. 콘솔 구매 결과가 Unity로 전달되거나 LiteDB에 로그로 저장된다고 가정하지 않는다.
```
