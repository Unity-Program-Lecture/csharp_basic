# 📘 C# 매개변수 한정자 가이드: ref, out, in

오늘의 목표는 **"함수에게 데이터를 줄 때, '복사본'을 줄 것인지 '원본'을 줄 것인지 결정하는 법을 배운다"**입니다.

---

## 1. 기본값: 값 전달 (Pass by Value)
아무것도 붙이지 않으면 함수는 데이터를 **'복사'**해서 가져갑니다.

- **비유**: 친구에게 내 시험지 **복사본**을 주는 것과 같습니다. 친구가 복사본에 낙서를 해도 내 **원본 시험지**는 깨끗합니다.
- **특징**: 함수 내부에서 값을 바꿔도 함수 밖의 원본 변수에는 아무 영향이 없습니다.

---

## 2. ref (참조 전달 - Read/Write)
- **비유**: 친구에게 내 **원본 시험지**를 직접 주는 것입니다. 친구가 거기다 낙서를 하면 내 시험지도 낙서가 된 채로 돌아옵니다.
- **특징**:
  1. 함수 안에서 값을 바꾸면 **함수 밖의 원본도 바뀝니다.**
  2. 함수에 넣기 전에 **반드시 값이 미리 들어있어야(초기화)** 합니다. (종이에 내용이 적혀 있어야 함)

```csharp
void LevelUp(ref int level) 
{
    level++; // 원본을 직접 수정!
}

int myLevel = 10;
LevelUp(ref myLevel); // 이제 myLevel은 11이 됩니다.
```

---

## 3. out (출력전용 - Write Only)
- **비유**: 친구에게 **빈 종이**를 주면서 "여기다 답 좀 적어서 돌려줘"라고 부탁하는 것과 같습니다.
- **특징**:
  1. 함수에 넣기 전에는 빈 종이어도 상관없습니다.
  2. **함수가 끝나기 전에 반드시 값을 채워야 합니다.** (안 채우면 컴파일러가 화를 냅니다!)
  3. 주로 **'결과값'**을 여러 개 받아와야 할 때 사용합니다. (예: `TryGetValue`)

```csharp
void GetPlayerInfo(out string name, out int hp) 
{
    name = "전사"; // 반드시 값을 채워야 함
    hp = 100;
}

string pName;
int pHP;
GetPlayerInfo(out pName, out pHP); // 함수가 답을 채워서 돌려줍니다.
```

---

## 4. in (입력전용 - Read Only)
- **비유**: 친구에게 내 시험지를 **유리판 밑에 깔아서** 보여주는 것입니다. 볼 수는 있지만, **글씨를 쓸 수는 없습니다.**
- **특징**:
  1. 원본을 참조하므로 '복사' 비용이 들지 않아 **성능상 이점**이 있습니다.
  2. 하지만 함수 안에서 값을 **절대로 수정할 수 없습니다.**
  3. 구조체(Struct)처럼 덩치가 큰 데이터를 안전하게 전달할 때 주로 씁니다.

```csharp
void PrintStatus(in int hp) 
{
    // hp = 50; // 에러! 수정할 수 없습니다.
    Console.WriteLine("현재 체력: " + hp);
}
```

---

## 🤝 한눈에 비교하기

| 구분 | 의미 | 필수 조건 | 함수 안에서의 권한 |
| :--- | :--- | :--- | :--- |
| **(Default)** | 복사본 전달 | 없음 (초기화 권장) | 맘대로 바꿔도 원본 무관 |
| **ref** | 원본 전달 | **미리 값이 있어야 함** | 읽기 / 쓰기 모두 가능 |
| **out** | 결과 받기 | 없음 (비어있어도 됨) | **반드시 값을 채워야 함** |
| **in** | 읽기전용 원본 | 미리 값이 있어야 함 | **읽기만 가능 (수정 불가)** |
